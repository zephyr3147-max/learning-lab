# 二叉树：考试最小背诵版

配套 [完整单文件 C 代码](二叉树_考试最小背诵版.c)，可以直接复制编译。这里只保留先序建树、三种递归遍历、结点数、叶子数、树高与销毁；层序、查找、镜像、深拷贝看上一级模块。

## 背诵顺序

1. 结点：数据 + 左孩子指针 + 右孩子指针。
2. 递归出口：空树直接返回，计数/高度则返回 0。
3. 先序根左右、中序左根右、后序左右根。
4. 结点数：左 + 右 + 1；树高：max(左, 右) + 1。
5. 叶子：左右孩子同时为空；非叶子递归求和。
6. 建树：读一个值，# 返回空；否则申请根、建左、建右。
7. 销毁：先销毁左、再销毁右、最后 free 根并置 NULL。

## 两个指针问题

`BiTNode* tree` 可以访问并修改已有结点的内容；如果要让调用者的根指针改变，需要 `BiTNode** tree`，调用时传 `&根指针`。

`const char** cursor` 用来修改调用者当前读取位置；`++(*cursor)` 移动字符指针，不是给字符值加 1。

简版 `CreateTree` 是有前置条件的递归函数：两个参数地址必须有效，`*cursor` 指向合法的以零结尾字符串，`*tree` 初始为 NULL。main 在外部检查整个串是否恰好读完；需要更完整的公共接口检查时用模块版 `BTCreate`。

## 示例与输出

输入写在 main 中：`ABD##E##C#F##`，其中每个 # 表示一个空孩子。

```text
ABDECF
DBEACF
DEBFCA
nodes=6 leaves=3 height=3
```

在上一级文件夹运行 `build.bat exam`。本简版用 int 计数，面向考试中的小树；模块版使用 size_t。两版都采用递归，树很深时受调用栈限制。

## 必须会解释

- 遍历中访问根的位置为什么决定先序、中序、后序？
- 为什么叶子判断是 &&，而不是 ||？
- 为什么高度取最大值，而不是将左右高度相加？
- 为什么销毁不能先 free 根再处理孩子？
- 为什么带 # 的先序可以恢复形状，而不带 # 的一般不行？

先独立回答，再对照源码；完整章节练习与复杂度表见上一级 [知识点与易错点](../知识点与易错点.md)。
