# 树与二叉树：知识点、复杂度与自测

## 树、二叉树与常用性质

树表示层次关系。结点的度是孩子数，树的度是所有结点度的最大值；叶子度为 0。兄弟有同一个双亲；路径长度通常按边数计。高度按层数计时，根深度为 1；按边数计深度的资料则将根深度记为 0，注意统一。

二叉树的每个结点最多两个孩子，并区分左右。它与普通“度不超过 2 的有序树”的定义不能完全等同：单孩子在二叉树中仍区分左、右位置。

以下统一根为第 1 层，空树高度 0：

| 性质 | 适用条件与理由 |
| --- | --- |
| 第 k 层至多 2^(k-1) 个结点 | k≥1；每往下一层最多翻倍 |
| 高 h 的二叉树至多 2^h−1 个结点 | h≥1；逐层上界相加 |
| 非空 n 结点树，最小高度 floor(log2 n)+1，最大高度 n | 最矮尽量紧凑，最高退化成链 |
| n0=n2+1 | 非空二叉树；n−1 条边，同时 n−1=n1+2n2 |
| n 个结点有 n+1 个空孩子指针 | 普通二叉链表，2n 个孩子位置减去 n−1 条边；非空树 n≥1 |
| 完全二叉树高为 floor(log2 n)+1，叶子数 ceil(n/2) | 非空；紧凑层序编号下，i>floor(n/2) 的结点都是叶子 |

中国教材常用“满二叉树”表示每层都满，即结点总数为 2^h−1。英文 full binary tree 常指每个结点有 0 或 2 个孩子，不能直接拿它代入上述满层公式。

完全二叉树：除最后一层外全满，最后一层从左到右连续排列。满二叉树必然完全，完全二叉树不一定满。仅凭高度达到最小值，不能断定是完全二叉树。

顺序存储（下标从 1 开始）：双亲 floor(i/2)，左孩子 2i，右孩子 2i+1；访问前检查下标合法且该位置确实有结点。下标从 0 开始时，孩子为 2i+1、2i+2；i>0 时双亲为 floor((i−1)/2)。普通稀疏二叉树保留这些位置会浪费空间。

## 从遍历序列还原树

数据值互不相同的前提下：

- 先序 + 中序：先序第一个是根，中序根两边分出左右子树。
- 后序 + 中序：后序最后一个是根，同样按中序划分。
- 只有先序 + 后序：一般不能唯一确定，如单孩子无法区分左右。
- 带完整空标记的先序：可唯一确定普通二叉树，不要求数据值互异。

有重复值时，仅凭两种普通遍历序列一般不能保证唯一。切分子树时按长度对应两个序列，不能凭字母大小决定左右；普通二叉树不是二叉搜索树。

## 树、森林与孩子兄弟表示

| 表示方法 | 含义 | 适合做什么 |
| --- | --- | --- |
| 双亲表示法 | 每个结点保存双亲下标，根用约定的特殊值 | 快速找双亲；找孩子通常要扫描 |
| 孩子表示法 | 每个结点保存孩子链表 | 枚举某结点的所有孩子 |
| 孩子兄弟表示法 | firstChild 指向第一个孩子，nextSibling 指向下一个兄弟 | 用两个指针表示任意多叉树 |

孩子兄弟表示法中，“左指针”连第一个孩子，“右指针”连下一兄弟。森林的各棵树根也通过兄弟指针连接。它们是同一表示约定下的转换，不意味着兄弟变成了原树中的父子。

常见遍历对应：树的先根对应转换后二叉树的先序；树的后根对应转换后二叉树的中序。森林的先序、中序分别对应转换后二叉树的先序、中序，先核对教材对森林遍历的命名。

练习提示：先画一个根有 3 个孩子的树，保留第一个孩子连线，再把三个孩子依次串成兄弟链。

## 线索二叉树

普通二叉链表有许多空指针，可用来保存某种遍历顺序下的前驱、后继。必须加标记区分“孩子”与“线索”，例如 ltag/rtag 为 0 表示孩子，1 表示线索。

中序线索：左空指针可连中序前驱，右空指针可连中序后继。找中序后继时：右标记为线索就沿它走；右边是真孩子则进入右子树，再沿真实左孩子找到最左结点。

不能把普通遍历和销毁函数直接用于线索树，否则可能沿线索回访或重复释放。头结点和首尾线索取值有多种教材约定，应按题面判断。本目录 `BiTree.c` 只适用于普通无环、无共享结点的二叉树。

## 哈夫曼树与编码

给定非负叶子权值，反复取权值最小的两棵树，建立权为两者之和的新根，放回森林，直到只剩一棵。

WPL = Σ(叶子权值 × 根到该叶子的边数)。这里路径长度按边数；不要把第 1 层叶子的深度 1 当作路径长度 1。

例如权值 2、3、7：先合并 2+3=5，再合并 5+7=12。WPL=5+12=17，也等于 2×2+3×2+7×1。每一次合并值的总和就是 WPL，因为每次合并使这两个子树中所有叶子的路径增加一条边。

| 考点 | 注意 |
| --- | --- |
| m 个叶子的二叉哈夫曼树有 2m−1 个结点 | m≥1；每个内部结点恰有两个孩子 |
| 哈夫曼编码为前缀编码 | 任何一个码字都不是另一个码字的前缀；每个符号对应叶子 |
| 权值相同可能有不同树与编码 | 最优 WPL 仍相同，左右标 0/1 的约定也会影响具体码字 |
| 只有一个权值 | 按树路径定义 WPL=0；实际码字是否约定为 0 应看题目 |
| 算法复杂度 | 每次线性寻找两个最小值一般 O(m²)；最小堆维护森林可为 O(m log m)，辅助空间 O(m) |

## 普通二叉树模块复杂度

n 为结点数，h 为树高；不计回调自身额外成本及分配器内部成本。

| 接口 | 时间 | 辅助空间 | 说明 |
| --- | --- | --- | --- |
| BTCreate | 合法输入 O(n) | O(h) 调用栈 | 新树占 O(n)，输入字符串另计；失败沿已读部分清理 |
| BTPreOrder / BTInOrder / BTPostOrder | O(n) | O(h) | 退化链上 h=n |
| BTLevelOrder | O(n) | O(n) | 本版先计数再分配 n 个指针；计数还有 O(h) 栈 |
| BTCount / BTLeafCount / BTHeight | O(n) | O(h) | 计算高度不等于只走最长路径 |
| BTFind | 最坏 O(n) | 最坏 O(h) | 普通树没有搜索树的左右大小关系 |
| BTMirror / BTDestroy | O(n) | O(h) | 镜像原地交换；销毁释放结点存储 |
| BTCopy | O(n) | O(h) | 新副本存储另占 O(n) |

模块面向学习中的中小规模树。极深链可能耗尽递归栈；代码未限制高度，也未实现迭代销毁。不要因正常样例通过就认为可处理任意深输入。

## C 与 C++ 对比：本章先理解用途

| C 当前写法 | C++ 后续写法 | 解决的问题 |
| --- | --- | --- |
| struct + 独立函数 | class + public/private | 把根指针与操作封装，减少外部破坏结构 |
| BiTNode** 修改调用者指针 | BiTNode*& 引用参数 | 用引用给指针变量起别名，需先学习引用语法 |
| malloc/free + 手动 Destroy | 构造/析构、RAII | 让对象生命周期管理资源 |
| 固定 char | template<typename T> | 同一结构支持多种数据类型 |
| 显式深拷贝 | 明确拷贝构造、赋值与所有权 | 避免默认浅拷贝导致重复释放 |
| 手写层序队列/非递归栈 | std::queue / std::stack | 专注遍历逻辑 |
| 自定义普通二叉树 | STL 没有直接对应的通用 binary_tree 容器 | set/map 有排序键语义，不能代替任意形状的普通二叉树 |

后续再按“C → class → 模板 → STL 对比”推进；这里不要求立即掌握所有 C++ 写法。

## 章节练习：先做，遇到困难再看提示

### 3 道基础题

1. 对指南中的 A～F 示例树，写四种遍历、树高、叶子数，并画出先序递归返回的位置。
2. 非空二叉树有 8 个度为 2 的结点、5 个度为 1 的结点，叶子数与总结点数是多少？提示：先列边数等式。
3. 分别画出 3 个结点的满二叉树与只向左延伸的二叉树。它们的树高、结点数、叶子数分别是多少？

### 2 道提高题

1. 不用递归实现中序遍历，并分析辅助空间。提示：栈保存尚未访问根的结点，外层条件包含“当前指针非空或栈非空”。
2. 根据互不相同的先序和中序序列重建二叉树，并拒绝长度不一致、重复值或集合不一致的输入。提示：先序取根，中序分两边，再检查各段长度和内容。

### 1 道综合编程题

读入一个用 `#` 表示空结点的先序字符串，创建普通二叉树。输出四种遍历、结点数、叶子数和树高；创建深拷贝，在副本上镜像并输出先序，确认原树不变，最后销毁两棵树。

先画 `ABD##E##C#F##` 对应的树，再写调用次序。必须处理空树、单结点、退化链、无效编码、创建失败；不能直接将原根指针赋给副本当作复制。先写 main 的调用骨架，基础函数可复用本目录模块。

## 我的易错点记录

以下为待自查项，尚未根据你的答题表现认定为已犯错误。

- [ ] 混淆度、层次、高度、路径长度及根的编号约定。
- [ ] 把普通二叉树当作二叉搜索树。
- [ ] 把完全二叉树与每层都满混淆。
- [ ] 叶子判断写成“任意一个孩子为空”，应是左右都空。
- [ ] 树高使用左右高度之和；或错误地认为求树高只需 O(h)。
- [ ] 递归忘记空树出口，或把一次返回误认为全部结束。
- [ ] 先序建树遗漏 #，或把 # 也分配成结点。
- [ ] 需要修改根指针时只传根指针副本。
- [ ] free 父结点后再读取孩子。
- [ ] 浅拷贝后把同一棵树释放两次。
- [ ] 层序入队 NULL，或只检查 p 而忘记栈里还有结点。
- [ ] 将按 1 编号的双亲/孩子公式用于按 0 编号的数组。

- [ ] 线索指针与真实孩子不作区分。
