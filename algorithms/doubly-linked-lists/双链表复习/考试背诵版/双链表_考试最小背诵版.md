# 双链表：C 语言考试最小背诵版

## 1. 本版本采用哪种双链表

采用**带头结点、循环、整数双链表**。结点包含 data、prev、next，分别保存数据、前驱地址、后继地址。所有接口和 main 放在一个 .c 文件中；不用头文件卫士，不引入 C++ 特性。

与单链表相比，每个结点多一个 prev，因此能往前走；与非循环链表相比，尾结点 next 指回头结点，头结点 prev 指向尾结点。

注意：双链表不一定循环、也不一定带头结点。考试如果指定别的形式，必须调整判空、遍历终点和边界处理，不能直接套本版本。

建议背诵：结点定义 → 初始化 → 四句插入 → 两句断链与释放 → 遍历终点。取值与查找是普通扫描。main 是调用示例，不必逐字背。

## 2. 基本结构与空表

```text
正向：head → 10 → 20 → head
反向：head → 20 → 10 → head

非空：head->next 指首结点，head->prev 指尾结点。
空表：head->next == head，head->prev == head。
销毁：外部 head == NULL。
```

头指针是一个变量，头结点是真实申请的结点；头结点不算数据元素。本版本保持：

- p->next->prev == p。
- p->prev->next == p。
- 从头结点沿任一方向走，会回到同一个头结点。
- 循环终点是头结点，不是 NULL。

DLinkList 是 Node *，所以 Init/Destroy 接收 &L（Node **）来修改外部头指针；其他接口接收 L（头结点地址）。

## 3. 完整单文件代码

使用前声明 DLinkList L = NULL，再检查初始化成功。Locate/Print 假设传入有效已初始化的头结点；输出参数指向表外的有效整数变量。禁止复制头指针后当两张独立表销毁，也不要人为破坏双向链接。

插入位置为 1..n+1，取值/删除位置为 1..n。Init/Get/Insert/Delete 返回 1 成功、0 失败；Locate 返回第一个匹配位置或 0。所有控制语句体都加大括号。

配套 .c 与下方代码相同，独立编译，不与其他程序的 main 一起链接。

```c
#include <stdio.h>
#include <stdlib.h>

typedef int ElemType;
typedef struct Node
{
    ElemType data;
    struct Node *prev;
    struct Node *next;
} Node;
typedef Node *DLinkList;

/* 初始化：申请头结点，让 prev/next 都指回自身。O(1)。
 * 参数为外部头指针地址，调用前头指针必须为 NULL。
 * 成功返回 1，参数非法、重复初始化或分配失败返回 0。
 */
int InitList(DLinkList *L)
{
    if (L == NULL || *L != NULL)
    {
        return 0;
    }
    *L = malloc(sizeof(Node));
    if (*L == NULL)
    {
        return 0;
    }
    (*L)->prev = *L;
    (*L)->next = *L;
    return 1;
}

/* 取第 i 个数据元素：位置为 1..n，e 接收结果。最坏 O(n)。
 * 成功返回 1，失败返回 0 且不修改输出。
 */
int GetElem(const Node *L, int i, ElemType *e)
{
    if (L == NULL || i < 1 || e == NULL)
    {
        return 0;
    }
    const Node *p = L->next;
    int j = 1;
    while (p != L && j < i)
    {
        p = p->next;
        ++j;
    }
    if (p == L)
    {
        return 0;
    }
    *e = p->data;
    return 1;
}

/* 查找第一个等于 e 的值，返回从 1 开始的位置或 0。最坏 O(n)。 */
int LocateElem(const Node *L, ElemType e)
{
    int i = 0;
    for (const Node *p = L->next; p != L; p = p->next)
    {
        ++i;
        if (p->data == e)
        {
            return i;
        }
    }
    return 0;
}

/* 在第 i 个位置插入 e：合法范围 1..n+1。最坏 O(n)。
 * 成功返回 1；位置非法或分配失败返回 0，原表不变。
 */
int ListInsert(DLinkList L, int i, ElemType e)
{
    if (L == NULL || i < 1)
    {
        return 0;
    }
    Node *p = L->next;
    int j = 1;
    while (p != L && j < i)
    {
        p = p->next;
        ++j;
    }
    if (j != i)
    {
        return 0;
    }
    Node *s = malloc(sizeof(Node));
    if (s == NULL)
    {
        return 0;
    }
    s->data = e;
    s->next = p;
    s->prev = p->prev;
    p->prev->next = s;
    p->prev = s;
    return 1;
}

/* 删除第 i 个数据结点，e 接收被删值，可传 NULL。最坏 O(n)。
 * 成功返回 1；位置非法返回 0，原表和输出值不变。
 */
int ListDelete(DLinkList L, int i, ElemType *e)
{
    if (L == NULL || i < 1)
    {
        return 0;
    }
    Node *p = L->next;
    int j = 1;
    while (p != L && j < i)
    {
        p = p->next;
        ++j;
    }
    if (p == L)
    {
        return 0;
    }
    if (e != NULL)
    {
        *e = p->data;
    }
    p->prev->next = p->next;
    p->next->prev = p->prev;
    free(p);
    return 1;
}

/* 正向输出：不打印头结点，遇到头结点停止。O(n)。 */
void PrintList(const Node *L)
{
    for (const Node *p = L->next; p != L; p = p->next)
    {
        if (p != L->next)
        {
            printf(" ");
        }
        printf("%d", p->data);
    }
    printf("\n");
}

/* 销毁：先释放数据结点，再释放头结点，外部头指针置 NULL。O(n)。 */
void DestroyList(DLinkList *L)
{
    if (L == NULL || *L == NULL)
    {
        return;
    }
    Node *p = (*L)->next;
    while (p != *L)
    {
        Node *next = p->next;
        free(p);
        p = next;
    }
    free(*L);
    *L = NULL;
}

/* 自动演示；考试按题目要求改写 main。 */
int main(void)
{
    DLinkList L = NULL;
    ElemType e;
    if (InitList(&L) == 0)
    {
        return 1;
    }
    if (ListInsert(L, 1, 10) == 0 || ListInsert(L, 2, 30) == 0
        || ListInsert(L, 2, 20) == 0)
    {
        DestroyList(&L);
        return 1;
    }
    PrintList(L);
    if (ListDelete(L, 2, &e) == 0)
    {
        DestroyList(&L);
        return 1;
    }
    printf("deleted: %d\n", e);
    PrintList(L);
    if (GetElem(L, 2, &e) == 0)
    {
        DestroyList(&L);
        return 1;
    }
    printf("second: %d\n", e);
    printf("position of 30: %d\n", LocateElem(L, 30));
    DestroyList(&L);
    return 0;
}
```

预期输出（程序自动演示，不要求输入）：

```text
10 20 30
deleted: 20
10 30
second: 30
position of 30: 2
```

## 4. 插入原理：在 p 前插入 s

按位置找到 p：插入第 i 位就是在原第 i 个结点前插入；尾插时 p 是头结点，合法位置 i=n+1；空表插第 1 位也在头结点前。

原有关系是 left 与 p 互为前后邻居，插入后变为 left、s、p：

```c
s->next = p;
s->prev = p->prev;
p->prev->next = s;
p->prev = s;
```

先让新结点保存两边，再修改两边的链接。不能先改 p->prev=s 再用 p->prev 找原前驱，否则入口已经变化。

口诀：**新结点先接两边，两边再接新结点。**

不要只改 next 而忘记 prev。头结点统一了空表、头插、尾插的写法，无需为每种情况另写一套断链规则。

## 5. 删除原理：让两边越过 p

```c
p->prev->next = p->next;
p->next->prev = p->prev;
free(p);
```

先确认 p 是数据结点而不是头结点；要取被删值，先保存 p->data；释放后不能再访问 p。

口诀：**前驱接后继，后继接前驱，最后释放。**

如果只有一个数据结点，这两句会自动让头结点 next/prev 都指回自身。不存在的数据位置不能删除头结点。

## 6. 遍历与销毁的区别

正向遍历从 L->next 出发，遇到 L 停止；反向从 L->prev 出发，沿 prev 走，遇到 L 停止。不用 while(p != NULL)，因为合法循环链表不会到 NULL。

销毁前先保存 next，再 free 当前数据结点。数据结点全部释放后，再 free 头结点，最后 *L=NULL。与普通单链表直接走到 NULL 的销毁方法不同。

## 7. 复杂度与适用场景

设 n 为数据结点数，按单次 malloc/free 作为基本操作分析：

| 操作 | 时间 | 原因 |
|---|---|---|
| 初始化、判空 | O(1) | 一个头结点/检查自身链接 |
| 按位取值、按值查找 | 最坏 O(n) | 仍需逐结点定位 |
| 本代码按位插入、按位删除 | 最坏 O(n) | 包括寻找目标 |
| 已知目标结点，在前面插入或删除 | O(1) | 只改少量链接 |
| 直接头插、尾插、头删、尾删 | O(1) | 首尾由头结点直接取得 |
| 遍历、销毁 | O(n) | 处理全部结点 |

上表“直接尾插 O(1)”指使用 head 的地址直接在其前面插入；本代码 ListInsert(L,n+1,x) 仍是按位置寻找，不能写成 O(1)。模块化版会另给 PushBack/PopBack，利用 head->prev 避免遍历。

辅助空间 O(1)，链表存储 O(n)，每个结点保存两根指针。双向并不等于随机访问；若没有缓存表长，本版求长度仍需 O(n) 遍历。

典型应用：

1. 双端队列：首尾均可 O(1) 增删。
2. 浏览历史或撤销/重做的链式组织：可以向前、向后移动；具体业务还需管理当前位置和截断规则。
3. 已取得结点地址的删除：不必再寻找前驱，单链表则通常需要前驱。
4. 作为有序合并、逆置、整链拼接等链表算法练习的基础。

不适合频繁按下标随机访问；结点分配和额外指针也有成本。LRU 常采用“哈希表 + 双链表”，并非只靠双链表就能按键 O(1) 查找。

## 8. 运行与版本隔离

同目录 .c 是独立程序。VS Code 编译时只选这个文件；模块化版另有自己的 main，不能一起编译链接。

有 GCC 时可在此目录运行：

```text
gcc -std=c99 -Wall -Wextra -pedantic "双链表_考试最小背诵版.c" -o dlist_exam
```

Windows 运行 ./dlist_exam.exe，Linux 运行 ./dlist_exam。编译环境必须事先配置好。build 内的检查代码不是背诵内容。

## 9. 总结、对照与练习

最小总结：空表双向指自身；插入四句、删除两句；遍历回头停止；头结点不存有效元素；分配失败不修改原链接。

### C 与 C++ 对照（先了解）

| C 实现 | 后续 C++ 学习方向 |
|---|---|
| struct、函数、malloc/free | class 封装、构造/析构、RAII |
| int 元素类型 | 模板复用结点链接逻辑 |
| 自己维护 prev/next | 标准库 list 提供双向链表；实现细节不由本教材假定 |

### 3 道基础题

1. 空表的 next/prev 为什么不能设为 NULL？提示：本版本是循环链表。
2. 插入时为什么先设置 s->prev，再修改 p->prev？提示：原前驱入口还要使用。
3. 删除唯一数据结点后，头结点的两个指针分别指向哪里？

### 2 道提高题

1. 写反向输出接口，要求不修改原表。提示：从 head->prev 出发。
2. 写直接尾删接口，要求 O(1)。提示：用 head->prev 取得尾结点，不按位置遍历。

### 1 道综合编程题

输入 n 个整数，建立循环双链表，按位置插入一个值，再删除第一个等于指定值的结点，输出正向与反向结果，最后释放链表。提示：建表维护尾部即可 O(n)，位置非法时按题目规定退出或跳过。
