# 双链表模块化进阶复习指南（C 语言）

## 先确定学习对象

本目录统一使用 **带头结点的循环双链表**，数据类型为 int。

- 双向：每个结点有 prev 和 next，分别指向前驱和后继。
- 带头：额外的头结点不存有效数据，位置 1 是头结点之后的第一个数据结点。
- 循环：首结点的 prev 指向头，尾结点的 next 指向头。
- 空表：头结点存在，prev 和 next 都指向头自身。
- 销毁后：头结点也释放，外部头指针变成 NULL。

“有头结点的空表”和“已经销毁的表”不是一回事。并非所有双链表都循环或带头，本章只讲这一种实现。

建议顺序：先看考试背诵版，再按下面 8 个阶段读模块。不要一次背完 29 个接口。
这一章继续使用 C，不需要学习 class、模板或 STL 才能看懂。

## 阶段 1：结点、头指针、空表——先只学这一点

~~~c
typedef struct DListNode
{
    ElemType data;
    struct DListNode *prev;
    struct DListNode *next;
} DListNode;

typedef DListNode *DLinkList;
~~~

data 是实际值；prev、next 是结点地址。
双链表比单链表多了 prev，因此已知某结点地址时，能直接找到它的前驱。

含两个数据结点时：

~~~text
L（头） <-> [10] <-> [20]
  ^                   |
  +------ next -------+

沿 next：头 → 10 → 20 → 头
沿 prev：头 → 20 → 10 → 头
~~~

每个结点必须满足：

~~~c
p->next->prev == p
p->prev->next == p
~~~

这两个关系是检查双向链接是否正确的重要条件。

### 为什么初始化传 &L？

~~~c
DLinkList L = NULL;
if (DListInit(&L) == DLIST_ERR)
{
    return 1;
}
~~~

类型关系：

| 表达式 | 实际类型 | 含义 |
| --- | --- | --- |
| L | DListNode * | 外部头指针变量保存的结点地址 |
| &L | DListNode ** | 外部头指针变量本身的地址 |
| 函数参数 DLinkList *L | DListNode ** | 用于修改调用者的头指针 |
| 函数中的 *L | DListNode * | 调用者的头指针 |

DListInit 需要把新头结点地址写回调用者，所以传 &L。
DListPushBack 只改结点内容和链接，不替换外部头指针，所以传 L。

初始化成功后的关键两句：

~~~c
head->prev = head;
head->next = head;
~~~

必须先把外部 L 初始化为 NULL，再调用 DListInit(&L)。
如果写成 DLinkList L; 就直接调用，*L 的值未初始化，读取它是错误行为。
重复初始化返回失败，避免覆盖原指针造成内存泄漏。

## 阶段 2：判空、求长、遍历、查找

先看这些接口：

~~~c
int DListEmpty(const DListNode *L);
int DListLength(const DListNode *L);
void DListPrint(const DListNode *L);
void DListPrintReverse(const DListNode *L);
DListNode *DListGetNode(DLinkList L, int i);
int DListGetElem(const DListNode *L, int i, ElemType *outValue);
int DListSetElem(DLinkList L, int i, ElemType value);
int DListLocateElem(const DListNode *L, ElemType value);
int DListPriorElem(const DListNode *L, ElemType value, ElemType *outValue);
int DListNextElem(const DListNode *L, ElemType value, ElemType *outValue);
~~~

- 判空：看 L->next 是否指回 L，O(1)。NULL 在本接口中不是已初始化空表，返回 0。
- 求长：本实现没有缓存 length，必须遍历计数，O(n)，不计头结点。
- 正向遍历：从 L->next 出发，走 next，遇 L 停止。
- 反向遍历：从 L->prev 出发，走 prev，遇 L 停止。
- 按位查找：从第一个数据结点起计数，位置从 1 开始。
- 按值查找：重复值只返回第一个匹配的位置；没有找到返回 0。
- 前驱/后继值：找第一个匹配的数据结点，再检查邻居是否为头结点。

循环链表不能使用 while (p != NULL) 遍历，否则正常链表也不会结束。

~~~c
for (const DListNode *p = L->next; p != L; p = p->next)
{
    printf("%d ", p->data);
}
~~~

const DListNode * 表示不能通过该指针直接修改该结点的字段。
它不是整个链表的“深度只读保证”；这里主要表达查询接口不应该修改表。

DListGetNode 返回数据结点地址，DListGetElem 返回数据值，两者不能混淆。
GetNode 的结果删除后立即失效；不要继续使用保存的地址。

~~~c
ElemType value;
if (DListGetElem(L, 2, &value) == DLIST_OK)
{
    printf("%d\n", value);
}
~~~

失败时 outValue 不改。因此不要在失败后输出一个原本未初始化的 value。
PriorElem 对首元素失败、NextElem 对尾元素失败：头结点不算它们的数据前驱/后继。

**练习：** 表为 10、20、20、30，LocateElem(L,20) 返回几？NextElem(L,20,&value) 得到几？

## 阶段 3：插入——先记住一个核心动作

这四个接口共用“在某结点前插入”的思想：

~~~c
int DListInsertBefore(DListNode *position, ElemType value);
int DListInsert(DLinkList L, int i, ElemType value);
int DListPushFront(DLinkList L, ElemType value);
int DListPushBack(DLinkList L, ElemType value);
~~~

在 p 前插入新结点 s：

~~~text
原来：a <-> p
变成：a <-> s <-> p
~~~

先完成新结点的两条链接，再修改原链表：

~~~c
s->next = p;
s->prev = p->prev;
p->prev->next = s;
p->prev = s;
~~~

不能先执行 p->prev = s，否则后面再读取 p->prev 时得到的是 s，而不是原前驱 a。

本模块先申请结点、检查成功，再改链接。因此 malloc 失败时原表不变。

| 接口 | 插入对象 | 定位成本 |
| --- | --- | --- |
| InsertBefore(p,x) | 已知 p，直接在它前面插入 | O(1) |
| PushFront(L,x) | 在 L->next 前插入 | O(1) |
| PushBack(L,x) | 在 L 前插入，即追加到尾部 | O(1) |
| Insert(L,i,x) | 先寻找第 i 个结点；i=n+1 时以头结点为目标 | 最坏 O(n) |

空表的 L->next 就是 L，所以头插、尾插都能使用同一个连接动作，无须另外处理空表。
按位插入的范围是 1..n+1；并不是只能插入已有位置 1..n。

**练习：** 10、30 中执行 Insert(L,2,20)，新结点的 prev、next 分别指向谁？

## 阶段 4：删除——绕开目标，再释放

~~~c
int DListErase(DLinkList L, DListNode *node, ElemType *outValue);
int DListDelete(DLinkList L, int i, ElemType *outValue);
int DListPopFront(DLinkList L, ElemType *outValue);
int DListPopBack(DLinkList L, ElemType *outValue);
int DListDeleteValue(DLinkList L, ElemType value);
int DListRemoveAll(DLinkList L, ElemType value);
~~~

删除 p：

~~~text
原来：a <-> p <-> b
变成：a <------> b
~~~

~~~c
p->prev->next = p->next;
p->next->prev = p->prev;
free(p);
~~~

free(p) 必须在读完 p 的链接之后；free 后不能再访问 p->next、p->prev 或 p->data。
outValue 用于取出被删值，可以传 NULL 表示不需要。输出变量必须在链表结点之外。

- Erase：已知属于本表的有效数据结点地址，O(1)。
- Delete：先按位置查找再删除，最坏 O(n)。
- PopFront/PopBack：直接使用 L->next/L->prev，O(1)。
- DeleteValue：找第一个匹配值再删除，最坏 O(n)。
- RemoveAll：一遍扫描删除全部匹配值，O(n)，返回删除数量。

Erase 为保持 O(1)，只检查 NULL 和是否为头结点，不遍历验证归属。
不要传别的链表的结点、已释放结点或任意内存地址！
合法性前提是接口契约的一部分，不是所有错误都能由函数自动查出。

RemoveAll 先保存 next，删除当前结点后使用保存的 next 继续。
否则连续相同值可能漏删，或者访问已释放内存。

**练习：** 2、2、1、2 执行 RemoveAll(L,2)，应该删除几个？剩下什么？

## 阶段 5：数组建表、清空、销毁

~~~c
int DListAssign(DLinkList L, const ElemType a[], int n);
void DListClear(DLinkList L);
void DListDestroy(DLinkList *L);
~~~

Assign 不是追加，而是用数组替换整张表，保持数组顺序：

~~~c
ElemType a[] = {10, 20, 30};
if (DListAssign(L, a, 3) == DLIST_ERR)
{
    /* 失败时旧表保留，可处理错误或销毁退出。 */
}
~~~

本实现先构建临时链；全部成功后才清空旧表并接入新结点。
如果中途分配失败，释放临时结点，保留旧表。
旧表 m 个、新表 n 个：总时间 O(m+n)，临时存储 O(n)，不是 O(1) 辅助空间。

源码里的 dummy 是栈上的临时头结点。只释放它挂着的数据结点，不能 free(&dummy)。
通过 Concat 转移新结点时会重新连接到真正的 L，不能留下指向临时头的链接。

| 操作 | 数据结点 | 头结点 | 操作后的外部 L |
| --- | --- | --- | --- |
| Clear(L) | 释放 | 保留并恢复自环 | 有效头地址 |
| Destroy(&L) | 释放 | 释放 | NULL |

销毁遍历需要先保存 next 再 free，最后才释放头结点。
DListDestroy 可重复调用；外部其他结点指针仍然可能悬空，不能继续访问。

**练习：** Clear 后能否直接 PushBack？Destroy 后要怎样才能再次 PushBack？

## 阶段 6：逆置和倒数第 k 个

~~~c
void DListReverse(DLinkList L);
int DListGetFromBack(const DListNode *L, int k, ElemType *outValue);
~~~

PrintReverse 只反向打印，表本身不变。
Reverse 交换每个结点的 prev、next，之后正向遍历的顺序就改变了。

逆置的核心：

~~~c
DListNode *p = L;
do
{
    DListNode *next = p->next;
    p->next = p->prev;
    p->prev = next;
    p = next;
} while (p != L);
~~~

- 包括头结点也要交换链接。
- next 保存“交换前的后继”，沿原方向完成整圈遍历。
- do...while 先执行一次，再判断；空表也只处理一次头结点。
- 不分配新结点，时间 O(n)、辅助空间 O(1)。

倒数第 1 个就是 L->prev。倒数第 k 个直接向前走 k-1 次。
有效 k 时 O(k)，最坏 O(n)。单链表没有 prev，通常要遍历或使用快慢指针。

**练习：** 10、20、30 逆置一次后的首尾是谁？逆置两次呢？

## 阶段 7：有序插入、拼接、有序合并

~~~c
int DListInsertOrdered(DLinkList L, ElemType value);
int DListConcat(DLinkList dest, DLinkList src);
int DListMergeSorted(DLinkList dest, DLinkList a, DLinkList b);
~~~

### 有序插入

前提：原表已经按非递减顺序排列。
扫描到第一个大于 value 的结点，在它前插入。
相等时继续走，因此新结点放在已有相同值之后。

函数不会自动排序，也不会先验证有序性。
如果原表无序，调用它不能保证结果有序。时间最坏 O(n)。

### 整链拼接

Concat(dest,src) 把 src 的全部数据结点接到 dest 尾部。
利用两个表的头指针直接找到首尾，只调整少量链接，不逐个搬运结点，因此 O(1)。

调用后 src 的头结点仍存在，但成为空表。
原 src 的数据结点归 dest 所有；原数据地址仍有效，但之后应作为 dest 的成员使用。

两个表必须独立，不能浅拷贝头指针或共享数据结点。
函数拒绝 NULL 和相同头指针，不扫描检查所有共享结点。

### 两个有序表合并

MergeSorted(dest,a,b)：

1. 要求 dest 为空；三个头结点必须不同，三张表独立。
2. 检查 a、b 是否非递减；不满足则返回失败，三张表不改。
3. 比较 a、b 当前首元素，小的结点摘下来接到 dest 尾部。
4. 相等时优先 a，保持各自内部顺序，因此是稳定合并。
5. 最后把剩余部分整链接到 dest。
6. a、b 变为空表；数据结点属于 dest。

不新建数据结点、不释放被合并的数据结点。
有序性检查和合并都为线性扫描，总时间 O(m+n)，辅助空间 O(1)。

~~~text
a：1 3 7
b：2 3 8
dest：1 2 3 3 7 8
~~~

## 阶段 8：复杂度、应用、练习与易错点

### 复杂度总表

除 Assign 外，下列接口不建立随 n 增长的临时容器，辅助空间 O(1)。
Insert 等操作新增的数据结点属于结果存储，应与辅助空间区分。

| 操作 | 时间复杂度 |
| --- | --- |
| Init、Empty | O(1) |
| Length、正反向遍历 | O(n) |
| GetNode/GetElem/SetElem/LocateElem/PriorElem/NextElem | 最坏 O(n) |
| 已知位置结点 InsertBefore、已知数据结点 Erase | O(1) |
| PushFront/PushBack/PopFront/PopBack | O(1) |
| 按位 Insert/Delete、按值 DeleteValue | 最坏 O(n) |
| RemoveAll、Clear、Destroy、Reverse | O(n) |
| GetFromBack | 有效 k 时 O(k)，最坏 O(n) |
| InsertOrdered | 最坏 O(n) |
| Assign | O(m+n)，临时空间 O(n) |
| Concat | O(1) |
| MergeSorted | O(m+n) |

本实现不保存 length，求长为 O(n)；位置查找从头向后走。
如果需要经常求长和按下标查找，可额外维护长度或选择顺序表；这不是双链表的优势。
单个结点多一个 prev 指针，会增加存储开销。

### 基本原理和应用

- 线性关系通过指针表示，结点内存不要求连续。
- 前后方向都能移动，已知结点时能快速断链。
- 带头循环结构让空表、首结点、尾结点的链接处理统一。
- 常见用途：双端队列、前后浏览、双向迭代、已知结点频繁插删。
- LRU 缓存常结合“哈希表 + 双链表”：哈希表定位，链表移动。
- 不适合频繁按下标随机访问；顺序表在这方面更合适。

### C 与 C++ 对比（先知道，不要求立即改写）

| 方面 | 本章 C | 后续 C++ |
| --- | --- | --- |
| 数据表示 | struct + 指针 | class 封装数据与操作 |
| 初始化/释放 | 显式 Init/Destroy | 构造/析构、RAII 管理资源 |
| 类型通用性 | typedef int ElemType | 模板参数表示元素类型 |
| 双向链表 | 自己维护 prev/next | 可考虑 std::list |
| 学习价值 | 理解指针、链接与资源所有权 | 减少业务代码中的手工内存管理 |

std::list 不支持数组式随机下标访问；它的内部实现细节不必与本章完全相同。
目前只要求掌握左侧 C 语言原理。

### 本章总结

1. 数据结点有 data、prev、next；头结点不算元素。
2. 空表是头结点自环，不是 NULL。
3. 在 p 前插入记四句，删除 p 记两句后 free。
4. 头尾地址已知，因此头尾插删 O(1)。
5. 按位/按值操作包含查找，最坏 O(n)。
6. 清空保留头；销毁连头释放并修改外部指针。
7. 拼接和合并转移结点所有权，不复制链表来冒充独立副本。
