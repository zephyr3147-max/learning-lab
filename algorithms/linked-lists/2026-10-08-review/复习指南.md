## 1. 第一课：结点、头指针与头结点

本节只抓住一个核心：**单链表通过 next 连接结点，不是连续数组。**

```c
typedef int ElemType;

typedef struct SListNode
{
    ElemType data;
    struct SListNode *next;
} SListNode;

typedef SListNode *LinkList;
```

data 保存一个整数；next 保存下一个结点的地址。定义结构体内部的 next 时，使用 struct SListNode，因为结尾处的类型别名 SListNode 还没有完成定义。

```text
L → 头结点 → [10 | next] → [20 | next] → [30 | NULL]
     第0个        第1个          第2个          第3个
```

头指针 L 是一个变量；头结点是申请出来的一块真实结点内存。头结点不算数据元素，遍历从 L->next 开始；非空表的首结点才是第一个数据结点。

```text
空表：     L → 头结点 → NULL
销毁后：   L == NULL
```

本模块的头结点 data 设为 0，但它不是有效元素，不能因此把空表说成“有一个 0”。结点可以位于不连续的内存地址，逻辑顺序由 next 决定。

自测：如果表中保存 10、20，实际申请了几个结点？判空应检查 L 还是 L->next？

### 为什么有的接口传 L，有的传 &L

```c
LinkList L = NULL;
int status = SListInit(&L);
```

LinkList 是 SListNode * 的类型别名，所以 LinkList * 实际上是 SListNode **。

| 参数 | 实际含义 | 调用 |
|---|---|---|
| LinkList L | 头结点地址的副本，能修改结点的 next | SListInsert(L, 1, 10) |
| LinkList *L | 外部头指针变量的地址，能修改外部 L | SListInit(&L)、SListDestroy(&L) |
| ElemType *outValue | 接收结果的表外整数变量地址 | SListGetElem(L, 1, &x) |

传入指针副本仍能修改指向的对象；只给这个副本赋新地址，却不能改变外部头指针。初始化、销毁需要更新外部 L，才用 &L。

查询接口使用 const SListNode *，不通过该指针修改结点字段，查询实现也不改变链接。输出参数必须指向链表外的有效整数变量，不要指向将被删除结点的 data。

SLIST_OK=1、SLIST_ERR=0 表示状态；Empty 返回条件是否成立；Locate 返回位置或 0；RemoveAll 返回删除数量。都是 int，但不要混用含义。

自测：把 Destroy 的参数改成 LinkList L，然后在函数中写 L=NULL，外部 L 会改变吗？

## 3. 第三课：初始化、判空、求长与遍历

接口：

```c
int SListInit(LinkList *L);
int SListEmpty(const SListNode *L);
int SListLength(const SListNode *L);
void SListPrint(const SListNode *L);
```

初始化申请一个头结点，并让 next 为 NULL。malloc 参数是 sizeof(*head) 或 sizeof(SListNode)，不是 sizeof(LinkList)；后者只是指针大小。申请失败返回 ERR，不能继续把 NULL 当有效头结点使用。

使用模板：

```c
LinkList L = NULL;
if (SListInit(&L) != SLIST_OK)
{
    return 1;
}

/* 在这里调用其他接口。 */

SListDestroy(&L);
```

本模块拒绝对活表重复初始化，避免把旧入口覆盖后泄漏。判空检查初始化后的 L->next；L=NULL 表示未初始化或已销毁，不是带头结点空表。Empty(NULL) 返回 0，Length(NULL) 返回 0 只是容错约定，不能靠 Length==0 判断是否已初始化。

求长和输出都从 L->next 沿 next 遍历，不计头结点。求长 O(n)，不像顺序表直接读 length 为 O(1)。本版链表没有预设固定容量，因此没有 Full 接口；是否还能新增结点取决于内存分配是否成功。

练习：初始化后输出 Empty 和 Length，预测结果，再编译运行。不要把头结点的 0 输出出来。

## 4. 第四课：按位置取值与修改

```c
int SListGetElem(const SListNode *L, int i, ElemType *outValue);
int SListSetElem(LinkList L, int i, ElemType value);
```

合法位置为 1..n。与顺序表的 data[i-1] 不同，链表必须逐结点找到目标。FindNode 从第一个数据结点出发，移动 i-1 次；Set 复用寻找前驱的助手，再修改前驱的后继值。

读取示例：

```c
ElemType x;
if (SListGetElem(L, 2, &x) == SLIST_OK)
{
    printf("%d\n", x);
}
```

只有成功后才能使用输出值。空表、位置 0、位置超过表长、输出地址为 NULL 都失败。修改只替换 data，不申请/删除结点，不改变链接。

练习：表为 10、20、30，先改第 2 个为 99，再读取第 2 个。若读取第 4 个失败，x 会不会被改？

## 5. 第五课：查找、前驱与后继

```c
int SListLocateElem(const SListNode *L, ElemType value);
int SListPriorElem(const SListNode *L, ElemType value, ElemType *outValue);
int SListNextElem(const SListNode *L, ElemType value, ElemType *outValue);
```

Locate 从头寻找第一个匹配，返回从 1 开始的位置。前驱/后继接口同样以第一个匹配为准，不返回结点地址，而是把相邻数据值写到 outValue。

例如 10、20、20、30：查找 20 返回 2；前驱为 10，后继为第二个 20。第一个数据元素没有数据前驱，不能把头结点当作前驱数据；最后一个元素没有后继。

前驱查询同时维护 prev 和 p。p 往后移动时，prev 跟随到 p 原来的位置，找到时便不需从头再找前驱。三个接口最坏都是 O(n)。

练习：在 20、20、30 中查询 20 的前驱，为什么失败，即使第二个 20 有前驱？

## 6. 第六课：按位插入、头插与尾插

```c
int SListInsert(LinkList L, int i, ElemType value);
int SListPushFront(LinkList L, ElemType value);
int SListPushBack(LinkList L, ElemType value);
```

插入合法范围为 1..n+1。FindPrev 从头结点（第 0 个）出发，走 i-1 次，得到新元素的前驱。i=1 时不走，i=n+1 时走到原尾结点；走到 NULL 表示位置过大。

InsertAfter 的关键步骤：

```c
SListNode *node = BuyNode(value);
if (node == NULL)
{
    return SLIST_ERR;
}
node->next = prev->next;
prev->next = node;
```

先创建并确认成功，再修改链接。新结点先接原后继，前驱再接新结点，不能颠倒。不像顺序表需要移动整段数据。

头插前驱就是已知头结点，O(1)；本版不缓存尾指针，单次尾插需找到尾结点，O(n)。如果已经有尾指针，链接尾插可 O(1)，后面的批量建表会利用这一点。

注意：ERR 同时可能表示位置非法或内存不足。题目要求“非法位置跳过但继续运行”时，先按已知表长检查范围，或使用细分错误码，不要把任何 ERR 都当作必须退出。

练习：在 10、30 的第 2 个位置插入 20，画出 prev、node、原后继。连续头插 1、2、3 后顺序是什么？

## 7. 第七课：按位删除、头删与尾删

```c
int SListDelete(LinkList L, int i, ElemType *outValue);
int SListPopFront(LinkList L, ElemType *outValue);
int SListPopBack(LinkList L, ElemType *outValue);
```

合法删除位置为 1..n。必须同时找到前驱，并确认它后面真的有数据结点。与插入不同：第 n+1 个位置可以插，但没有结点可删。

EraseAfter 的核心：

```c
SListNode *node = prev->next;
if (outValue != NULL)
{
    *outValue = node->data;
}
prev->next = node->next;
free(node);
```

顺序是保存必要值 → 断链 → 释放。outValue 可为 NULL，表示不接收被删值。删除失败时原表和输出不变；删除成功后，不再访问被释放结点，也不能继续使用指向它的旧指针。

头删 O(1)。单链表尾删需要知道尾结点的前驱，即使仅有尾指针也无法直接往前走，通常仍为 O(n)。不使用“复制后继再删除后继”的技巧，因为它不能处理尾结点且会改变结点身份。

练习：只有一个数据结点时，尾删的前驱是谁？删除后头结点还存在吗？

## 8. 第八课：按值删除与删除全部匹配值

```c
int SListDeleteValue(LinkList L, ElemType value);
int SListRemoveAll(LinkList L, ElemType value);
```

DeleteValue 只删除第一个匹配，找到时已经保留它的前驱。无需先 Locate 返回位置，再 Delete 重新定位，虽然那样也是 O(n)，却多遍历一次。

RemoveAll 处理所有匹配，包括连续重复值，时间 O(n)。删除后的关键是**prev 不前进**，继续检查新的 prev->next；未删除时才让 prev 向前。

例子：2、2、1、2、3、2，删除全部 2 后得到 1、3，返回 4。若删除后仍把 prev 往后移动，就可能漏掉连续的第二个 2。

返回值别混淆：DeleteValue 返回成功状态；RemoveAll 返回删除数量，0 表示没有匹配，未必是程序出错。

练习：对 7、7、7 删除全部 7，返回多少？清理后应保留什么？

## 9. 第九课：O(n) 批量建表与分配失败保护

```c
int SListAssign(LinkList L, const ElemType a[], int n);
```

此接口从外部数组替换建表，顺序与数组一致。它不是在原表后追加。n=0 时清空，允许 a=NULL；n<0 或 n>0 且 a=NULL 时失败。数组必须实际包含 n 个可读元素。

反复调用本版 PushBack，需要每次重新找末尾，建立 n 个元素总时间 O(n²)。Assign 使用临时尾指针，只走新结点一次：

```c
SListNode dummy = {0, NULL};
SListNode *tail = &dummy;

/* 每个 node 都已申请成功并设置 next=NULL。 */
tail->next = node;
tail = node;
```

dummy 是局部临时头结点，不是 malloc 出来的，不能 free 它。暂时申请的数据结点挂在 dummy 后面；若中途失败，SListClear(&dummy) 只释放其后数据结点，保留原表。

所有新结点都创建成功后，才清理旧表并接入新链：

```c
SListClear(L);
L->next = dummy.next;
```

接入后结点由 L 管理，不能再释放 dummy 后面的新链。旧表有 m 个元素、新数组 n 个元素时，总时间 O(m+n)；为保持失败时原表不变，临时新链需要 O(n) 存储，峰值同时存在新旧结点。

与顺序表扩容一样，先保证分配成功，再提交修改，不能先把原表毁掉。

练习：原表为 10、20，建立新表 1、2、3 时第 3 次申请失败，原表应该是什么？前两次新申请的结点由谁释放？

## 10. 第十课：清空与销毁

```c
void SListClear(LinkList L);
void SListDestroy(LinkList *L);
```

Clear 从 L->next 开始，释放全部数据结点，最后 L->next=NULL，头结点保留，可继续插入。

Destroy 先 Clear，再 free 头结点，通过 *L=NULL 修改外部头指针。可以重复调用；销毁后再次使用时必须重新 Init。

释放循环：

```c
while (p != NULL)
{
    SListNode *next = p->next;
    free(p);
    p = next;
}
```

先保存 next，再释放 p。free 不会自动把调用者的变量设为 NULL；free(p) 后再写 p=p->next 会读取已释放内存。

对比顺序表：顺序表 Clear 只改 length，可 O(1)；此动态链表 Clear 要真正回收每个数据结点，是 O(n)。

练习：Clear 之后可以直接 PushFront 吗？Destroy 之后为什么不行？

## 11. 第十一课：原地逆置

```c
void SListReverse(LinkList L);
```

用 prev、current、next 三个指针，不申请新结点，也不交换 data：

```c
SListNode *prev = NULL;
SListNode *current = L->next;
while (current != NULL)
{
    SListNode *next = current->next;
    current->next = prev;
    prev = current;
    current = next;
}
L->next = prev;
```

next 保存还没处理的剩余链；current 改指向已经逆置的部分；prev 始终是逆置部分的首结点。处理结束后，把头结点接到 prev。

```text
原表：head → 10 → 20 → 30 → NULL
结果：head → 30 → 20 → 10 → NULL
```

空表、单元素表无需特殊循环处理。时间 O(n)，辅助空间 O(1)，数据结点的地址不变，但彼此链接方向改变。

练习：逆置两次能否恢复原顺序？为什么必须在修改 current->next 前保存 next？

## 12. 第十二课：快慢指针寻找中间元素

```c
int SListMiddle(const SListNode *L, ElemType *outValue);
```

slow、fast 从第一个数据结点出发；每轮 slow 走一步，fast 走两步。fast 到末尾时，slow 到中间。

```c
while (fast != NULL && fast->next != NULL)
{
    slow = slow->next;
    fast = fast->next->next;
}
```

先检查 fast，再访问 fast->next，利用 && 的短路求值避免空指针访问。

本版约定：奇数长度取唯一中间元素，偶数长度取靠后的中间元素。例如 1、2、3、4、5 返回 3；1、2、3、4 也返回 3。题目若要求靠前中间，要改变快指针的起点/终止规则。

不必先遍历求长度，O(n) 时间、O(1) 辅助空间。空表、非法输出地址失败且不改输出值。

练习：对 1、2、3、4，逐轮记录 slow、fast，验证为什么返回 3。

## 13. 第十三课：倒数第 k 个元素

```c
int SListKthFromEnd(const SListNode *L, int k, ElemType *outValue);
```

fast 与 slow 都从首数据结点出发。先让 fast 走 k 步，再让二者一起走，始终保持 k 个结点间距。fast 到 NULL 时，slow 就是倒数第 k 个。

例如 1、2、3、4、5，k=2 时返回 4；k=1 返回尾值 5；k=5 返回首值 1。k<1 或 k>n 失败，输出值不变。

先走 k 步时，每步都检查 fast 是否为 NULL；不能直接越过空指针。无需缓存全部结点或求两次长度，时间 O(n)、辅助空间 O(1)。

练习：为什么让 fast 先走 k 步而不是 k-1 步？对 k=1 画出末轮的位置。

## 14. 第十四课：有序合并与结点所有权

```c
int SListMergeSorted(LinkList dest, LinkList a, LinkList b);
```

这是本资料的最后一个进阶知识点，不必与基础插删一起背。dest、a、b 是三个独立、已初始化的链表，dest 必须为空；a、b 必须非递减有序，并且不能共享结点。

每次比较 pa、pb 的值，把较小结点接到 dest 的尾部，随后移动相应指针。相等时优先接 a 中的结点，保留每个输入中的原顺序；一个输入结束后，直接接上另一个剩余链。

```text
A：1 → 3 → 3 → 7
B：2 → 3 → 8
C：1 → 2 → 3 → 3 → 3 → 7 → 8
```

本函数先检查参数、有序性，再修改链接；不符时返回 ERR，三张表不变。有序性检查加合并仍是 O(m+n)。合并不 malloc，也不复制 data，额外只用几个指针，辅助空间 O(1)。

实现末尾的 `pa != NULL ? pa : pb` 是 C 的条件运算符：pa 非空就选 pa，否则选 pb，即接入剩余链。

成功后：

- a、b 的头结点仍存在，但 next=NULL，变为空表。
- 所有数据结点由 dest 接管，最终由 dest 的 Clear/Destroy 释放。
- 三个头结点仍需分别 Destroy，不能把 a/b 原数据结点再释放一次。

不允许写 B=A 来建立独立输入，这只是复制指针。也不支持两个不同头结点共享同一尾链；独立所有权是本接口使用前提，而不是通过头指针不相等就能完全验证的事实。

练习：合并后分别 Destroy(&A)、Destroy(&B)、Destroy(&C)，为什么数据结点不会被重复 free？

## 15. 接口与复杂度总结

令 n 为当前表长，m 为旧表/另一输入的长度，按单次申请/释放作为基本操作分析，实际分配器耗时依实现而异。

| 接口 | 时间 | 额外空间 | 重点 |
|---|---|---|---|
| Init / Empty | O(1) | O(1) | 初始化与判空不同 |
| Length / Print | O(n) | O(1) | 不计头结点 |
| GetElem / SetElem | 最坏 O(n) | O(1) | 需沿链接定位 |
| Locate / Prior / Next | 最坏 O(n) | O(1) | 以第一个匹配为准 |
| Insert / Delete | 最坏 O(n) | O(1) | 包含寻找前驱 |
| PushFront / PopFront | O(1) | O(1) | 头结点就是前驱 |
| PushBack / PopBack | O(n) | O(1) | 不缓存尾指针，无 prev |
| DeleteValue / RemoveAll | O(n) | O(1) | 一次遍历 |
| Assign | O(m+n) | 临时新链 O(n) | 成功后才替换旧链 |
| Clear / Destroy | O(n) | O(1) | 回收全部动态结点 |
| Reverse / Middle / KthFromEnd | O(n) | O(1) | 三指针/快慢指针/间距指针 |
| MergeSorted | O(m+n) | O(1) | 复用结点，转移所有权 |

整张链表的结点存储为 O(n)，与“算法辅助空间”不是一回事。插入申请一个结点是新增表存储；批量替换为保留旧表而同时建立的新链会带来 O(n) 峰值额外存储。

最小知识总结：头结点不计入元素；查位置要遍历；插删先找前驱；malloc/free 成对；清空留头、销毁去头；已知结点的链接调整才是 O(1)。

## 16. 测试程序怎么看

test.c 使用 REQUIRE 检查实际结果，不只是打印；它不是 assert 宏，即使定义 NDEBUG，调用和检查仍会执行。Check 对照元素顺序、末尾 NULL、表长、判空和按位取值。

覆盖：空表、非法位置、单元素、头尾插删、重复值、失败输出保留、重复销毁、奇偶中间元素、倒数位置边界、有序/无序输入合并、相同值的稳定顺序及结点转移。

默认脚本启用 SLIST_TEST_ALLOCATOR：在指定一次申请时返回 NULL，测试初始分配失败、插入失败和建表中途失败。这个钩子仅用于验证，普通构建仍直接使用 malloc。

ModelChecks 用小数组做参照，执行 1000 次确定性的插入、删除、修改、逆置、删除全部匹配值，每步比较实际链表内容。先有限步验证末尾再求长度，避免坏链接形成环时无限遍历。

本次没有引入测试框架、自动排序或复杂抽象。学习时只修改本节相关例子，保留其他检查，重新运行 build.bat test。

## 17. C 与 C++ 对照及章节练习

### C 与 C++ 对照（本次先不改写）

| 当前 C 方式 | 后续 C++ 可解决的问题 |
|---|---|
| struct 与普通函数 | class 把数据、接口封装在一起 |
| 手动 Init/Destroy | 构造/析构与 RAII 管理生命周期 |
| 固定 ElemType=int | 模板复用链接逻辑，支持不同类型 |
| 手工结点链接 | forward_list 提供单链表容器；list 是双向链表 |

改成 C++ 不会让按位置查找单链表自动变成 O(1)。当前不要求理解类、模板或迭代器，先把 C 实现的所有权和指针操作理解透。

### 3 道基础题

1. 插入第 1 个元素与删除第 1 个元素，为什么都能使用头结点作前驱？提示：头结点记为第 0 个。
2. 在 10、20、20、30 中，Locate、Prior、Next 查询 20 分别返回什么？提示：看第一个匹配。
3. Clear 与 Destroy 后，头指针和头结点各处于什么状态？提示：分别画空表和销毁后的图。

### 2 道提高题

1. 增加“有序表删除重复元素”接口，不改变其他元素相对顺序，只保留每种值一个。提示：检查当前结点与后继，删除后不要漏掉连续重复值。
2. 为结构体另外缓存尾指针，让尾插 O(1)。提示：列出清空、头插空表、尾删、逆置、合并时尾指针必须怎样更新；这比只多一个字段更重要。

### 1 道综合编程题

输入 n 个整数建立链表，再输入插入位置与值；合法时插入，非法位置跳过；输入要删除的值，删除第一个匹配；输出并释放链表。基础版可复用接口；提高版要求建表 O(n)，不要反复遍历尾部。
