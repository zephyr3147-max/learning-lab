# 单链表：两个有序链表的合并

## 题目原文

【问题描述】
1. 建立两个有序的单链表，表中元素的数据类型自己指定；
2. 将建立的两个链表合并为一个新的有序的单链表；
3. 输出显示已合并好的有序的单链表。

【输入形式】输入表 1 的元素个数，表 1 的元素值（逆序）；同表 1，输入表 2 的数据。

【输出形式】输出合并后的元素值。

【样例输入】

```text
3
22 21 19
4
92 91 31 2
```

【原题样例输出】

```text
The current List is:
2,19,21,22,29,31,91
```

【样例说明】原题未提供。

【评分标准】原题未提供。

> 样例有笔误：输入有 92，没有 29。按给出的输入，正确结果应为下面的输出。实际输入只包含数字，不输入注释。

```text
The current List is:
2,19,21,22,31,91,92
```

## 思路与实现约定

元素类型取 int，使用带头结点的单链表。逆序输入表示按非递增顺序输入，头插后得到非递减链表。本程序依赖题目的有序输入前提，不另做排序。

头插建表 → 比较两个当前结点 → 较小结点接到结果尾部 → 接上剩余部分 → 输出 → 释放。

输入 `22 21 19` 时：

```text
head → NULL
head → 22 → NULL
head → 21 → 22 → NULL
head → 19 → 21 → 22 → NULL
```

头插必须先保存原来的首结点，再修改头结点的 next：

```c
s->next = head->next;
head->next = s;
```

本版的“新链表”指使用独立头结点 C、复用 A 和 B 的数据结点。合并会拆开原链表，结束后 A、B 为空。如果要求保留原链表，则需要另行分配结点并复制数据，本版不采用该方式。重复元素全部保留。

## 完整 C 语言代码

配套源码：[单链表_有序合并_题解.c](单链表_有序合并_题解.c)。

```c
#define _CRT_SECURE_NO_WARNINGS
#include <stdio.h>
#include <stdlib.h>

typedef struct Node {
    int data;
    struct Node* next;
} Node;

/* 逆序输入，头插法建立升序链表。head 必须是空表的头结点。 */
int CreateList(Node* head)
{
    int n;
    int value;

    if (scanf("%d", &n) != 1 || n < 0) {
        return 0;
    }

    for (int i = 0; i < n; i++) {
        if (scanf("%d", &value) != 1) {
            return 0;
        }

        Node* s = (Node*)malloc(sizeof(Node));
        if (s == NULL) {
            return 0;
        }

        s->data = value;
        s->next = head->next;
        head->next = s;
    }

    return 1;
}

/* A、B 是互不共享数据结点的升序表，C 是独立的空表。 */
void MergeList(Node* A, Node* B, Node* C)
{
    Node* p = A->next;
    Node* q = B->next;
    Node* tail = C;

    while (p != NULL && q != NULL) {
        if (p->data <= q->data) {
            tail->next = p;
            p = p->next;
        } else {
            tail->next = q;
            q = q->next;
        }

        tail = tail->next;
    }

    if (p != NULL) {
        tail->next = p;
    } else {
        tail->next = q;
    }

    /* 数据结点统一归 C 管理，避免通过 A、B 再次释放。 */
    A->next = NULL;
    B->next = NULL;
}

void PrintList(const Node* head)
{
    const Node* p = head->next;

    printf("The current List is:\n");

    while (p != NULL) {
        printf("%d", p->data);
        if (p->next != NULL) {
            printf(",");
        }
        p = p->next;
    }

    printf("\n");
}

/* 头结点是 main 的局部变量，只释放 malloc 分配的数据结点。 */
void DestroyList(Node* head)
{
    Node* p = head->next;

    while (p != NULL) {
        Node* next = p->next;
        free(p);
        p = next;
    }

    head->next = NULL;
}

int main(void)
{
    Node A = {0, NULL};
    Node B = {0, NULL};
    Node C = {0, NULL};

    if (!CreateList(&A) || !CreateList(&B)) {
        DestroyList(&A);
        DestroyList(&B);
        return EXIT_FAILURE;
    }

    MergeList(&A, &B, &C);
    PrintList(&C);
    DestroyList(&C);

    return EXIT_SUCCESS;
}
```

## 合并时的指针操作

### 1. 初始化三个指针

```c
Node* p = A->next;
Node* q = B->next;
Node* tail = C;
```

p、q 指向两条链表当前待比较的结点；tail 指向结果中最后一个已经选定的结点，最初是 C 的头结点。A、B、C 参数都是头结点的地址，因此 main 中传入 &A、&B、&C。这里修改的是头结点对象的 next 成员，不需要 Node**。

### 2. 选择较小结点，三步完成连接

当 p->data <= q->data 时：

```c
tail->next = p;       /* ① 修改链接：把 p 指向的结点接到结果尾部 */
p = p->next;          /* ② 移动 p：准备比较 A 中的下一个结点 */
tail = tail->next;    /* ③ 移动 tail：指向刚选中的结点 */
```

第一句修改结点内部的指针成员，后两句改变局部指针变量的指向。这些操作不会复制结点，也不会复制数据。

```text
操作前：
C → 2 → ...
    ↑ tail
19 → 21 → 22 → NULL
↑ p

操作后：
C → 2 → 19 → 21 → 22 → NULL
         ↑    ↑
        tail  p
```

注意：19->next 暂时仍指向 21，只有到 tail 为止的前缀是已经选定的结果。后续比较决定是否改写 tail->next，不必每轮都将它置为 NULL。

例如当前 p 指向 21、q 指向 20，下一轮会执行 tail->next = q，将 19 的 next 改为指向 20；p 仍保存 21 的地址，所以不会丢失 A 的剩余结点。

不能先让 p 前进再执行 tail->next = p，否则会跳过原本要接入的结点。也不能遗漏 tail 的前进，否则下一轮会覆盖同一个位置的链接。

选择 q 时完全对称：连接 q，移动 q，最后移动 tail。判断用 <=，相等时先取 A 的结点，但两个相等结点最终都会保留。

### 3. 一条链表取完，直接连接剩余部分

```c
if (p != NULL) {
    tail->next = p;
} else {
    tail->next = q;
}
```

剩余部分本身有序，且其值不小于已选定的尾部元素，因此直接连接整段即可。如果两条链表都为空，q 也是 NULL，结果依然为空表。

样例中的选择过程：

| 比较值 | 本轮选入 | 已选定的结果 |
|---|---|---|
| 19 和 2 | 2 | 2 |
| 19 和 31 | 19 | 2,19 |
| 21 和 31 | 21 | 2,19,21 |
| 22 和 31 | 22 | 2,19,21,22 |
| A 取完 | 接上 B 剩余部分 | 2,19,21,22,31,91,92 |

### 4. 结点的归属与释放

合并完成后将 A->next、B->next 设为 NULL，原来的数据结点统一由 C 管理。清空入口不会释放结点，也不会影响 C 中的链接。

三个头结点都是 main 的局部变量，不能 free(&A)、free(&B)、free(&C)。DestroyList 只释放 malloc 分配的数据结点，而且必须先保存 next 再 free(p)，否则访问 p->next 就会访问已经释放的内存。

CreateList 读入失败或 malloc 失败时返回 0；main 释放两条表中已建立的数据结点后失败退出。合并本身不分配内存。

## 复杂度与易错点

| 操作 | 时间复杂度 | 额外空间 |
|---|---|---|
| 建立两表 | O(m + n) | 数据结点占 O(m + n) |
| 合并 | O(m + n) | O(1)，复用原结点 |
| 输出与销毁 | O(m + n) | O(1) |

易错点：

- 输入逆序时用头插法；尾插会保留输入的降序顺序，与本合并函数的升序前提不符。
- 循环条件使用 &&：只有 p、q 都非 NULL 时才能比较二者的 data。
- 移动 p 或 q 后，还必须移动 tail。
- 合并结束要接上剩余整段，不能漏掉。
- 重复值不去重，输出最后一个数后不加逗号。
- C 必须是独立空表，A、B 不能共享数据结点。
- 头结点与数据结点的分配方式不同，不能混用释放方式。
