# 期末编程题：单链表输入、插入、查找、按值删除与输出

## 题目与约定

输入元素个数 n、n 个整数、插入位置与插入值、待删除的元素值。
输出完成插入和删除后的线性表。

- 插入位置从 1 开始，合法范围是 1..n+1。
- 插入位置非法：跳过插入，继续执行删除。
- 删除输入的元素值，不是删除该位置的元素。
- 题目未明确重复值处理，本版按常见约定删除第一个匹配结点；值不存在则不改表。
- 实际输入只有数字，不输入样例中的 // 说明。
- 各接口的 head 必须指向有效头结点，不允许操作已释放结点。

样例输入：

~~~text
5
1 2 3 4 5
3 6
4
~~~

样例输出：

~~~text
1 2 6 3 5
~~~

## 最小背诵思路

尾插建表 → 找插入位置的前驱 → 插入 → 按值找前驱 → 删除 → 输出 → 释放。

保留 tail，每个元素尾插 O(1)，完整建表 O(n)，避免反复从头找链尾导致 O(n²)。
插入、按值删除最坏 O(n)，输出与清理 O(n)，整体时间 O(n)，链表存储 O(n)。

本版 head 是 main 的局部头结点，只有数据结点用 malloc。
ClearList 只 free 数据结点，不能 free(&head)。
与“头结点也用 malloc”的通用背诵版不同，不要混用销毁方式。

## 完整单文件代码

```c
#define _CRT_SECURE_NO_WARNINGS
#include <stdio.h>
#include <stdlib.h>

typedef int ElemType;
typedef struct Node
{
    ElemType data;
    struct Node *next;
} Node;

/* 创建数据结点：失败返回 NULL。 */
Node *CreateNode(ElemType e)
{
    Node *p = malloc(sizeof(Node));
    if (p != NULL)
    {
        p->data = e;
        p->next = NULL;
    }
    return p;
}

/* 按位置插入：成功 1，位置非法 0，申请失败 -1。 */
int ListInsert(Node *head, int i, ElemType e)
{
    if (i < 1)
    {
        return 0;
    }
    Node *p = head;
    int j = 0;
    /* 头结点位置为 0，找第 i 个位置的前驱。 */
    while (p != NULL && j < i - 1)
    {
        p = p->next;
        ++j;
    }
    if (p == NULL)
    {
        return 0;
    }
    Node *s = CreateNode(e);
    if (s == NULL)
    {
        return -1;
    }
    s->next = p->next;
    p->next = s;
    return 1;
}

/* 查找第一个等于 e 的元素，返回前驱；未找到返回 NULL。 */
Node *FindPrev(Node *head, ElemType e)
{
    Node *p = head;
    while (p->next != NULL)
    {
        if (p->next->data == e)
        {
            return p;
        }
        p = p->next;
    }
    return NULL;
}

/* 按值删除第一个匹配结点；未找到不改表。 */
int DeleteValue(Node *head, ElemType e)
{
    Node *p = FindPrev(head, e);
    if (p == NULL)
    {
        return 0;
    }
    Node *q = p->next;
    p->next = q->next;
    free(q);
    return 1;
}

/* 输出数据元素，不输出头结点，无末尾多余空格。 */
void PrintList(const Node *head)
{
    const Node *p = head->next;
    while (p != NULL)
    {
        printf("%d", p->data);
        if (p->next != NULL)
        {
            printf(" ");
        }
        p = p->next;
    }
    printf("\n");
}

/* 释放全部数据结点，保留头结点。 */
void ClearList(Node *head)
{
    Node *p = head->next;
    while (p != NULL)
    {
        Node *next = p->next;
        free(p);
        p = next;
    }
    head->next = NULL;
}

int main(void)
{
    /* 局部头结点不需要 malloc，也不能 free(&head)。 */
    Node head = {0, NULL};
    Node *tail = &head;
    int n;
    if (scanf("%d", &n) != 1 || n < 0)
    {
        return 0;
    }
    /* 保留尾指针，每个元素录入 O(1)。 */
    for (int i = 0; i < n; ++i)
    {
        ElemType e;
        if (scanf("%d", &e) != 1)
        {
            ClearList(&head);
            return 0;
        }
        Node *s = CreateNode(e);
        if (s == NULL)
        {
            ClearList(&head);
            return 1;
        }
        tail->next = s;
        tail = s;
    }
    int position;
    ElemType value;
    if (scanf("%d %d", &position, &value) != 2)
    {
        ClearList(&head);
        return 0;
    }
    /* 非法位置不退出；申请失败才退出。 */
    if (ListInsert(&head, position, value) == -1)
    {
        ClearList(&head);
        return 1;
    }
    ElemType target;
    if (scanf("%d", &target) != 1)
    {
        ClearList(&head);
        return 0;
    }
    DeleteValue(&head, target);
    PrintList(&head);
    ClearList(&head);
    return 0;
}
```

## 必背的两组链接操作

插入：先让新结点保存原后继，再让前驱指向新结点。

~~~c
s->next = p->next;
p->next = s;
~~~

删除：FindPrev 返回待删除结点的前驱，不必第二次遍历找前驱。

~~~c
Node *q = p->next;
p->next = q->next;
free(q);
~~~

先断链再释放，不能 free 后读 q->next。

| ListInsert 返回值 | 含义 | main 的处理 |
| --- | --- | --- |
| 1 | 插入成功 | 继续删除 |
| 0 | 位置非法 | 跳过插入，继续删除 |
| -1 | 申请失败 | 清理后退出 |

样例过程：1 2 3 4 5 → 第 3 位插 6 → 1 2 6 3 4 5 → 删除值 4 → 1 2 6 3 5。

## 易错点

- [ ] 把头结点当成第一个数据元素。
- [ ] 非法插入就退出，没有继续删除。
- [ ] 把待删除值 4 当成第 4 个位置。
- [ ] 插入时先改 p->next，丢失原后继。
- [ ] 删除后读取已释放结点。
- [ ] free 局部头结点，或忘记释放数据结点。
- [ ] 输入 // 注释导致 scanf 失败。
- [ ] 把多个有 main 的考试文件一起编译。
