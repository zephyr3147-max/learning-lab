# 单链表：C 语言考试最小背诵版

## 1. 本次版本与背诵范围

本次按“单链表复习”整理，采用**带头结点、非循环、整数数据的单链表**。它与上一份顺序表的区别：不使用固定容量数组，而是逐个申请结点，用 next 把结点连接起来。

所有接口和 main 都放在同一个 .c 文件中，不拆成头文件和实现文件，因此本版本不需要头文件卫士。以后拆头文件时按你的习惯使用 #pragma once。

本次只保留七个常见核心接口：初始化、按位取值、按值查找、按位插入、按位删除、遍历、销毁。不加菜单、类、模板、尾指针或复杂框架。所有 if、for、while 的语句体都加大括号，包括单语句。

建议背诵顺序：结点定义 → 初始化 → 按位寻找 → 插入 → 删除 → 销毁。按值查找与遍历是普通的扫描；main 是调用示例，不必逐字背。

考试若指定“不带头结点”或“循环链表”，必须调整实现，不能原样套用本版本。

## 2. 基本原理：结点 + 指针

一个结点有两部分：data 保存数据，next 保存后继结点的地址。结点的内存地址不要求连续，先后顺序由 next 决定。

```text
L → 头结点 → [10 | next] → [20 | next] → [30 | NULL]
     不算第1个       第1个           第2个           第3个

空表：L → 头结点 → NULL
销毁后：L == NULL
```

- 头指针：变量 L，里面存储头结点地址。
- 头结点：为简化插删而额外建立的真实结点，不保存有效表元素，其 data 不应读取。
- 首结点：第一个数据结点，也就是 L->next；空表没有首结点。
- 空表判定：初始化成功后，L->next == NULL。
- 末尾判定：最后一个结点的 next 为 NULL。
- 接口位置从 1 开始；寻找前驱时把头结点视为第 0 个结点。

为什么加头结点？插入、删除第一个元素时，也有一个固定的前驱，即头结点，可以与中间位置使用相同代码。

### 两种参数一定要区分

LinkList 是 Node * 的类型别名，所以：

| 写法 | 实际类型 | 用途 | 调用示例 |
|---|---|---|---|
| LinkList L | Node * | 传入头结点地址，修改结点里的链接 | ListInsert(L, 1, 10) |
| LinkList *L | Node ** | 传入头指针变量的地址，修改外部头指针 | InitList(&L)、DestroyList(&L) |

C 语言参数是值传递。传入 Node * 的副本仍能修改它指向的结点，但只给形参重新赋值，不能改变外部的头指针变量。因此初始化和销毁需要指针的指针。

const Node * 用在查询接口中，表示不通过这个指针修改结点字段；查询函数本身遵守不修改链表的约定。

## 3. 完整单文件代码

配套文件：单链表_考试最小背诵版.c。独立编译这个文件，不要与顺序表程序一起链接，避免多个 main。

使用约定：

1. 声明 LinkList L = NULL，检查 InitList(&L) 成功后再使用链表。
2. 插入位置为 1..n+1，取值和删除位置为 1..n；不必预先遍历算长度，沿链检查位置即可。
3. Init/Get/Insert/Delete 返回 1 表示成功、0 表示失败；Locate 返回第一个匹配位置，找不到返回 0。
4. Get/Delete 的输出地址指向表外的有效整数变量，不要指向待删除结点内部；Delete 可传 NULL。
5. 不直接复制头指针来冒充独立副本，不手动修改链接形成环；销毁后必须重新初始化才能复用。
6. malloc 失败时返回失败；不保证任意规模都能分配成功。本版本的位置和计数使用 int。
7. 本代码只支持非循环链表；若人为形成环，遍历和销毁算法都不适用。

```c
#include <stdio.h>
#include <stdlib.h>

typedef int ElemType;
typedef struct Node
{
    ElemType data;
    struct Node *next;
} Node;
typedef Node *LinkList;

/* 初始化：申请头结点，建立带头结点的空表。O(1)。
 * L：头指针变量的地址，调用前该变量必须为 NULL。
 * 成功返回 1；参数非法、重复初始化或分配失败返回 0。
 */
int InitList(LinkList *L)
{
    if (L == NULL || *L != NULL)
    {
        return 0;
    }
    *L = malloc(sizeof(Node));
    if (*L == NULL)
    {
        return 0;
    }
    (*L)->next = NULL;
    return 1;
}

/* 按位取值：读取第 i 个数据结点，不改变原表。最坏 O(n)。
 * L：头结点地址；i：位置（1..n）；e：表外接收变量的地址。
 * 成功返回 1，失败返回 0 且不修改输出值。
 */
int GetElem(const Node *L, int i, ElemType *e)
{
    if (L == NULL || i < 1 || e == NULL)
    {
        return 0;
    }
    const Node *p = L->next;
    for (int j = 1; j < i && p != NULL; ++j)
    {
        p = p->next;
    }
    if (p == NULL)
    {
        return 0;
    }
    *e = p->data;
    return 1;
}

/* 按值查找：查找第一个值等于 e 的数据结点。最坏 O(n)。
 * L：头结点地址；e：要查找的值。
 * 返回从 1 开始的位置；未找到或 L 为 NULL 返回 0。
 */
int LocateElem(const Node *L, ElemType e)
{
    if (L == NULL)
    {
        return 0;
    }
    int i = 1;
    for (const Node *p = L->next; p != NULL; p = p->next)
    {
        if (p->data == e)
        {
            return i;
        }
        ++i;
    }
    return 0;
}

/* 插入：在第 i 个位置插入 e，先找第 i-1 个结点。最坏 O(n)。
 * L：头结点地址；i：位置（1..n+1）；e：新元素。
 * 成功返回 1；位置非法或分配失败返回 0，原表不变。
 */
int ListInsert(LinkList L, int i, ElemType e)
{
    if (L == NULL || i < 1)
    {
        return 0;
    }
    Node *p = L;
    for (int j = 0; j < i - 1 && p != NULL; ++j)
    {
        p = p->next;
    }
    if (p == NULL)
    {
        return 0;
    }
    Node *s = malloc(sizeof(Node));
    if (s == NULL)
    {
        return 0;
    }
    s->data = e;
    s->next = p->next;
    p->next = s;
    return 1;
}

/* 删除：删除第 i 个数据结点，先找它的前驱。最坏 O(n)。
 * L：头结点地址；i：位置（1..n）；e：表外接收变量的地址，
 * 可传 NULL 表示不接收。成功返回 1，失败返回 0 且原表不变。
 */
int ListDelete(LinkList L, int i, ElemType *e)
{
    if (L == NULL || i < 1)
    {
        return 0;
    }
    Node *p = L;
    for (int j = 0; j < i - 1 && p != NULL; ++j)
    {
        p = p->next;
    }
    if (p == NULL || p->next == NULL)
    {
        return 0;
    }
    Node *q = p->next;
    if (e != NULL)
    {
        *e = q->data;
    }
    p->next = q->next;
    free(q);
    return 1;
}

/* 遍历输出：依次打印数据结点，不打印头结点。O(n)。
 * L：头结点地址；不改原表，无返回值。空表输出换行。
 */
void PrintList(const Node *L)
{
    if (L == NULL)
    {
        return;
    }
    for (const Node *p = L->next; p != NULL; p = p->next)
    {
        if (p != L->next)
        {
            printf(" ");
        }
        printf("%d", p->data);
    }
    printf("\n");
}

/* 销毁：释放所有数据结点和头结点，再把外部头指针置为 NULL。
 * L：头指针变量的地址；可重复调用，无返回值。O(n)。
 */
void DestroyList(LinkList *L)
{
    if (L == NULL)
    {
        return;
    }
    Node *p = *L;
    while (p != NULL)
    {
        Node *next = p->next;
        free(p);
        p = next;
    }
    *L = NULL;
}

/* 调用示例：这部分帮助理解接口，不必逐字背诵。 */
int main(void)
{
    LinkList L = NULL;
    ElemType e;
    if (InitList(&L) == 0)
    {
        return 1;
    }
    if (ListInsert(L, 1, 10) == 0 || ListInsert(L, 2, 30) == 0
        || ListInsert(L, 2, 20) == 0)
    {
        DestroyList(&L);
        return 1;
    }
    PrintList(L);
    if (ListDelete(L, 2, &e) == 0)
    {
        DestroyList(&L);
        return 1;
    }
    printf("deleted: %d\n", e);
    PrintList(L);
    if (GetElem(L, 2, &e) == 0)
    {
        DestroyList(&L);
        return 1;
    }
    printf("second: %d\n", e);
    printf("position of 30: %d\n", LocateElem(L, 30));
    DestroyList(&L);
    return 0;
}
```

预期演示输出（程序自动运行，不需要输入）：

```text
10 20 30
deleted: 20
10 30
second: 30
position of 30: 2
```

## 4. 抓住三个核心操作

### 4.1 初始化：创建头结点

InitList(&L) 先申请一个 Node 大小的内存，再令头结点的 next 为 NULL。头结点的 data 未初始化，但不会把它当作有效元素读取。

malloc(sizeof(Node)) 表示申请“一个完整结点”的字节数；只申请 sizeof(Node *) 得到的只是指针大小，不够存放整个结点。C 中不必强制转换 malloc 的返回值，要包含 stdlib.h。

InitList 前必须让 L 为 NULL；对已经初始化的活表再次调用会返回失败，避免丢失原入口。不要先给局部 L 随意赋一个地址。

### 4.2 插入：找前驱，新结点接后继，再让前驱接新结点

在第 i 个位置插入，需要找到第 i-1 个结点 p。p 从头结点出发，移动 i-1 次：

- i = 1：移动 0 次，p 就是头结点。
- i = 2：移动 1 次，p 是第一个数据结点。
- i = n+1：p 是最后一个数据结点，允许尾插。
- 移动后 p 为 NULL：说明不存在这样的前驱，位置非法。

新结点 s 申请成功后，最重要的两句是：

```c
s->next = p->next;
p->next = s;
```

口诀：**新结点先接后面，前驱再接新结点。**

不能颠倒，否则 s->next 可能变成 s 自己，并丢失原后继。整个插入不会搬动原来的数据结点，只新增结点并修改链接。分配失败时不改变原表。

### 4.3 删除：找前驱，保存目标，越过目标，释放目标

同样找到第 i-1 个结点 p，还要确认 p->next 存在。删除的核心是：

```c
Node *q = p->next;
p->next = q->next;
free(q);
```

需要接收被删值时，在 free(q) 之前保存 q->data。只断开链接却不 free 会泄漏；free 后再读 q->data 或 q->next 是访问已释放内存。

考试容易混淆：删除“第 i 个”时，找的是“第 i-1 个前驱”，不是让 p 指到第 i 个再删除 p->next。

### 4.4 销毁：先存 next，再 free

DestroyList(&L) 从头结点开始，把全部结点逐个释放。关键顺序：

```c
Node *next = p->next;
free(p);
p = next;
```

保存 next 的原因：释放 p 后就不能再读取 p->next。最后通过 *L = NULL 把外部头指针清空，避免外部 L 留下悬空地址。free 不会自动把调用者的指针设为 NULL。

销毁与清空不同：

- 清空：释放所有数据结点，保留头结点，最后头结点的 next 为 NULL。
- 销毁：包括头结点一起释放，最后外部 L 为 NULL。
- 本背诵版只提供 DestroyList。需要清空接口时，可保留头结点实现，或反复删除第 1 个元素。

## 5. 复杂度、优缺点与应用

设 n 为数据结点数量，以下是包括定位过程的时间复杂度：

| 接口/操作 | 时间复杂度 | 辅助空间 | 原因 |
|---|---|---|---|
| 初始化 | O(1) | O(1) | 只申请一个头结点 |
| 判空 | O(1) | O(1) | 检查 L->next |
| 求表长（本版本不缓存长度） | O(n) | O(1) | 数数据结点 |
| 按位取值 | 最坏 O(n) | O(1) | 必须沿 next 找位置 |
| 按值查找 | 最坏 O(n) | O(1) | 逐个比较数据 |
| 按位插入 | 最坏 O(n) | O(1) | 定位前驱后只调整少量指针 |
| 按位删除 | 最坏 O(n) | O(1) | 定位前驱后只调整少量指针 |
| 头插、头删 | O(1) | O(1) | 前驱就是已知头结点 |
| 尾插（本版本无尾指针） | O(n) | O(1) | 必须找到末尾 |
| 遍历、销毁 | O(n) | O(1) | 逐个处理结点 |
| 已知前驱时的链接插入/删除 | O(1) | O(1) | 不包含寻找前驱的时间 |

上述通常按单次 malloc/free 作为基本操作分析，实际分配器耗时依实现而异。插入申请的一个新结点是新增表存储；除结点存储外，算法局部变量只占 O(1)。整张链表占 O(n)，每个结点都额外保存 next 指针。

### 与顺序表对比

| 特点 | 顺序表 | 本版本单链表 |
|---|---|---|
| 存储 | 连续数组 | 独立结点通过指针连接 |
| 第 i 个元素访问 | O(1) | 最坏 O(n) |
| 一般位置插删 | 移动后续元素 | 寻找前驱，再改链接 |
| 容量 | 固定或整体动态扩容 | 按结点申请，受内存限制 |
| 额外空间 | 动态版可能预留未用容量 | 每个结点有 next 开销 |
| 使用后处理 | 动态数组需 free；固定数组不需 | 逐个 free，包括申请的头结点 |

不要把“链表插删只改指针”背成“链表所有插删都是 O(1)”：通过位置查找前驱仍是 O(n)。

### 常见应用

1. 头部频繁增删：可实现链式栈，头插入栈、头删出栈。
2. 动态数据集合：无需预设固定元素容量；已知前驱后可插删，不搬动其他结点。
3. 链式队列：头删出队、尾插入队。要让尾插也为 O(1)，需额外维护尾指针；本版未维护。
4. 单链表算法题：逆置、合并有序链表、删除指定值、查找中间结点等。

不适合频繁按编号取第 k 条记录的情况，因为不能直接随机访问。也不支持从当前结点直接向前走；双向链表才有 prev 指针。

## 7. 考前总结、C++ 对照与练习

### 最小背诵口诀

- 带头空表：L 不为空，L->next 为空。
- 插入、删除：先找前驱，第 i 个要找第 i-1 个。
- 插入：先新接后，再前接新。
- 删除：先存目标，再越过目标，最后释放。
- 销毁：先存 next，再 free，最后清空头指针。
- 链表按位访问 O(n)，已知前驱时的链接调整 O(1)。

### C 与 C++ 对照（只了解，不在本次引入）

| 当前 C 写法 | 后续 C++ 学习方向 | 不变的底层原理 |
|---|---|---|
| struct + 函数 | class 封装接口 | 结点之间靠链接连接 |
| InitList / DestroyList | 构造函数 / 析构函数 | 申请与释放必须匹配 |
| 固定 ElemType 为 int | 模板支持不同类型 | 链接操作不依赖整数值 |

标准库 list 是双向链表，并非本次单链表；forward_list 是单链表。当前先掌握 C 指针，不要求立即改用这些 C++ 特性。

### 3 道基础题

1. 带头结点空表的 L 为 NULL 吗？为什么判断 L->next？提示：画出空表的头结点。
2. 插入第 1 个元素时，前驱 p 是谁？插入第 3 个时需要移动几次？提示：头结点记为第 0 个。
3. 为什么删除后需要 free(q)，但又不能先 free 再读 q->next？提示：断链与释放是两件事。

### 2 道提高题

1. 只使用头插，输入 1、2、3 后最终顺序是什么？提示：每个新元素放在最前面，再思考如何保持原输入顺序。
2. 添加 ClearList，要求只释放数据结点、保留头结点。提示：从 L->next 开始释放，最后重设 L->next。

### 1 道综合编程题

输入 n 个整数，建立带头结点单链表；输入插入位置和新值，合法则插入并输出，不合法则不输出；最后释放整表。提示：初学可复用 ListInsert 建表；若反复用按位尾插，建表总时间是 O(n²)，提高版可用临时尾指针把建表优化到 O(n)。

### 易错点自查（待你实际练习后再记录错误）

- [ ] 没有把头结点当成第一个数据元素输出或计数。
- [ ] 初始化、销毁传 &L，普通查询和插删传 L。
- [ ] malloc 申请的是 sizeof(Node)，不是 sizeof(Node *)。
- [ ] 新结点申请失败时不改链接。
- [ ] 插入先设置 s->next，再设置 p->next。
- [ ] 删除先保存必要内容，再 free。
- [ ] 销毁逐个保存后继，不访问释放后的结点。
- [ ] 区分空表（有头结点）与销毁后（没有头结点）。
- [ ] if、for、while 的单语句体也加大括号。
