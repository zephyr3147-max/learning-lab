# 栈：考试最小背诵版（C，单文件）

## 1. 原理：后进先出 LIFO

栈是一种限制插入、删除位置的线性表，只在栈顶操作。
10、20、30 依次入栈，出栈顺序是 30、20、10，像叠盘子一样先取最上面的。

本版是固定容量顺序栈：数组保存数据，top 表示最后一个有效元素的下标。

| 状态 | 条件 |
| --- | --- |
| 空栈 | top == -1 |
| 一个元素 | top == 0 |
| 满栈 | top == MAXSIZE - 1 |
| 元素数 | top + 1 |

入栈：先检查是否已满，再 ++top 存值。
出栈：先检查是否为空，再取 data[top]，然后 --top。
GetTop 只看值，Pop 会删除逻辑上的栈顶。
本版所有 S 参数必须指向已经初始化的有效对象；取值输出参数指向表外有效变量。
Pop 的输出参数可以为 NULL 表示不取值，GetTop 不允许 NULL。

## 2. 完整单文件代码

只背基本接口；main 是无须输入的演示，考试按题目输入输出改写。

```c
#include <stdio.h>
#define MAXSIZE 100
typedef int ElemType;

typedef struct
{
    ElemType data[MAXSIZE];
    int top;
} SqStack;

/* 初始化：top=-1 表示没有数据元素。O(1)。 */
void InitStack(SqStack *S)
{
    S->top = -1;
}

/* 判空：没有栈顶数据结点。O(1)。 */
int StackEmpty(const SqStack *S)
{
    return S->top == -1;
}

/* 求长：栈顶下标加 1。O(1)。 */
int StackLength(const SqStack *S)
{
    return S->top + 1;
}

/* 入栈：先检查满，再移动 top 并存入值。O(1)。 */
int Push(SqStack *S, ElemType e)
{
    if (S->top == MAXSIZE - 1)
    {
        return 0;
    }
    S->data[++S->top] = e;
    return 1;
}

/* 出栈：读取栈顶后 top 减 1；e 可为 NULL。O(1)。 */
int Pop(SqStack *S, ElemType *e)
{
    if (StackEmpty(S))
    {
        return 0;
    }
    if (e != NULL)
    {
        *e = S->data[S->top];
    }
    --S->top;
    return 1;
}

/* 取栈顶：只读取，不删除；失败不改输出。O(1)。 */
int GetTop(const SqStack *S, ElemType *e)
{
    if (StackEmpty(S) || e == NULL)
    {
        return 0;
    }
    *e = S->data[S->top];
    return 1;
}

/* 清空：固定数组无需 free，仅恢复空栈状态。O(1)。 */
void ClearStack(SqStack *S)
{
    S->top = -1;
}

/* 自动演示：顺序入栈 10、20、30，按 30、20、10 出栈。 */
int main(void)
{
    SqStack S;
    InitStack(&S);
    if (!Push(&S, 10) || !Push(&S, 20) || !Push(&S, 30))
    {
        return 1;
    }
    ElemType e;
    if (GetTop(&S, &e))
    {
        printf("top: %d\n", e);
    }
    while (Pop(&S, &e))
    {
        printf("%d", e);
        if (!StackEmpty(&S))
        {
            printf(" ");
        }
    }
    printf("\n");
    ClearStack(&S);
    return 0;
}
```

输出：

```text
top: 30
30 20 10
```

## 3. 最小记忆

```c
/* 空 */
top = -1;
/* 入：先增后存 */
data[++top] = e;
/* 出：先读后减 */
e = data[top--];
```

这些只是记忆片段，实际函数必须先检查满/空。
不是每一种栈都用 top=-1；进阶版用 size 表示元素数，不能混用两套公式。
固定数组没有 malloc，所以不需要 Destroy/free，Clear 只重置 top。

## 4. 复杂度与应用

初始化、判空、求长、入栈、出栈、取栈顶、清空都是 O(1)。
结构本身固定占用 MAXSIZE 个元素的存储，本算法没有额外线性临时空间。
适用：括号匹配、表达式求值、深度优先搜索、逆序处理、撤销操作。
递归调用的调用栈也具有后进先出的特点，但不是直接调用这里的 Push/Pop。

## 5. 与 C++ 的联系

| C | 后续 C++ |
| --- | --- |
| struct + 函数 | class 封装 |
| 手工检查数组容量 | vector 或自定义动态栈 |
| Push / Pop / GetTop | std::stack 的 push / pop / top |

C++ std::stack 的 pop 不返回被删值，通常先 top 再 pop；现在先掌握 C 版即可。

## 6. 练习与易错点

3 道基础题：

1. 空栈 top 为多少？满栈 top 为多少？
2. 依次 Push 1、2，Pop 一次，再 Push 3，之后全部出栈是什么顺序？
3. GetTop 与 Pop 有什么区别？

2 道提高题：

1. 用两个栈实现先进先出的队列，说明元素何时需要搬运。
2. 用栈判断包含 ()、[]、{} 的括号序列是否匹配。

综合题：输入 n 和 n 个整数，入栈后按出栈顺序输出；超容量或读入失败要处理。
提示：Init → 循环 Push → 循环 Pop；不要先写完整答案，先预测样例顺序。

易错点记录：

- [ ] top 下标与元素数混淆。
- [ ] 没检查空/满就访问数组。
- [ ] 把先增后存写成先存后增，与 top=-1 约定冲突。
- [ ] 以为出栈必须把原数组内容擦除。
- [ ] 误用 free 释放结构体内部的固定数组。
