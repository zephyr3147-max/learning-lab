# 算法与数据结构

每道题或一次练习使用独立目录，记录题目链接、核心思路、复杂度、边界条件和测试结果。

建议命名：`YYYY-MM-DD-题号或主题/`。同一道题的不同解法可放在同一目录中。学习记录可复制 [通用模板](../templates/study-note.md)。
