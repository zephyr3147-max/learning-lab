# 删除递增线性表中多余元素

## 题目与约定

来源：[CG 第二章题面](https://cg.sau.edu.cn/assignment/problemContent.jsp?problemID=XTl7Mh3qfII)，作业 12208。
代码：[06_有序链表去重.c](06_有序链表去重.c)，独立编译提交。

输入有序整数序列，读到 EOF；没有长度，也没有 -1 结束标志。每个值保留一次，重复结点立即释放。

样例输入：

```text
1 2 2 3
```

样例输出：

```text
1 2 3
```

## 思路与函数

ReadList 建表 → Deduplicate 去重 → PrintList 输出。有序表的相同值相邻；相等就删除后继，p 不移动；不同才前进。

## 关键代码

```c
Node* q = p->next;
p->next = q->next;
free(q);
```

## 样例推演

p 到达第一个 2，删除第二个 2 后仍停在第一个 2；新后继是 3，不相等才前进。

## 复杂度

O(n) 时间，链表存储 O(n)，去重辅助空间 O(1)。

## 边界与易错点

空表、单结点、全相同、连续重复值均需考虑。-1 是普通数据；循环检查 p 和 p->next；删除后 p 不前进。Windows 手动输入用 Ctrl+Z 后回车表示 EOF。

按考试数据处理：输入符合题面，长度和位序用 int，规模在可表示、可分配范围内。只用 stdio.h、stdlib.h，分配时仅做一次简短的 NULL 检查。剩余链表结点随进程结束回收，局部头结点不能 free。
