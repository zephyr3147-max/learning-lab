# 线性表：顺序结构

## 题目与约定

来源：[CG 第二章题面](https://cg.sau.edu.cn/assignment/problemContent.jsp?problemID=yCoHMGRDt5s)，作业 12208。
代码：[02_线性表_顺序结构.c](02_线性表_顺序结构.c)，独立编译提交。

读 n、n 个元素、插入位序和插入值。合法位序为 1..n+1；越界直接结束，不输出。

样例输入：

```text
3
1 2 3
2 4
```

样例输出：

```text
1 4 2 3
```

## 思路与函数

ReadList 一次分配 n+1 个连续位置，读入 n 个元素；Insert 从后往前右移，填入新值并增加 length；PrintList 输出。本题只有一次插入，预留一个空位即可。

## 关键代码

```c
for (int i = L->length; i >= pos; --i)
{
    L->data[i] = L->data[i - 1];
}
L->data[pos - 1] = value;
```

## 样例推演

pos=2 对应下标 1；先移动 3，再移动 2，最后在下标 1 写入 4。

## 复杂度

O(n) 时间，顺序表存储 O(n)，插入辅助空间 O(1)。

## 边界与易错点

空表可在第 1 位插入，n+1 表示尾插；位序减 1 才是下标；必须从后往前移动。Insert 要求已预留一个空位，本题只调用一次；main 最后 free 数组。

按考试数据处理：输入符合题面，长度和位序用 int，规模在可表示、可分配范围内。只用 stdio.h、stdlib.h，分配时仅做一次简短的 NULL 检查。只预留本题一次插入所需的空间，不实现通用扩容。
