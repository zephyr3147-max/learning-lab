# 交替合并两个单链表

## 题目与约定

来源：[CG 第二章题面](https://cg.sau.edu.cn/assignment/problemContent.jsp?problemID=M5UkF3oWphM)，作业 12208。
代码：[03_交替合并.c](03_交替合并.c)，独立编译提交。

读 m、n，接着读 A 的 m 个值、B 的 n 个值。合并复用原结点且不依赖长度。输入支持空格或逗号，输出中文逗号分隔（依据原有 CG 提交记录）。

样例输入：

```text
2 3
1 3
2 4 5
```

样例输出：

```text
1，2，3，4，5
```

## 思路与函数

ReadList 建表 → Merge 交替取 A、B 的结点 → PrintList 输出。一表耗尽后直接接上另一表剩余段；长度只用于读入，不传给 Merge。

## 关键代码

```c
tail->next = a;
a = a->next;
tail = tail->next;
```

## 样例推演

先接 1、2，再接 3、4；A 为空后，把 B 剩余的 5 接上。a、b 指向剩余段，tail 指向结果表尾。

## 复杂度

O(m+n) 时间，结点存储 O(m+n)，合并辅助空间 O(1)。

## 边界与易错点

支持空表和长度不同的表；合并时不能新建数据结点。合并后 A、B 不再当成独立表使用。题面只有符号样例，上述是练习样例。ReadInt 的 `%*[^0-9-]` 跳过分隔符，星号表示不保存跳过的字符，再用 `%d` 读整数。

按考试数据处理：输入符合题面，长度和位序用 int，规模在可表示、可分配范围内。只用 stdio.h、stdlib.h，分配时仅做一次简短的 NULL 检查。剩余链表结点随进程结束回收，局部头结点不能 free。
