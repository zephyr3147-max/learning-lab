# 两个有序链表的合并

## 题目与约定

来源：[CG 第二章题面](https://cg.sau.edu.cn/assignment/problemContent.jsp?problemID=f_n6ZLiFb1Q)，作业 12208。
代码：[05_有序链表合并.c](05_有序链表合并.c)，独立编译提交。

输入两个升序整数序列，各以 -1 结束；输出升序合并结果，空格分隔，重复值全部保留。

样例输入：

```text
1 3 4 5 6 9 -1
2 3 7 8 12 -1
```

样例输出：

```text
1 2 3 3 4 5 6 7 8 9 12
```

## 思路与函数

ReadList 建表 → Merge 归并 → PrintList 输出。比较两表当前值，每次接入较小结点，相等时先取 A；一表耗尽后接上另一表剩余段。

## 关键代码

```c
tail->next = a != NULL ? a : b;
```

## 样例推演

先接 1、2，随后两个 3 都接入；A 耗尽后直接连接 B 的剩余结点 12。

## 复杂度

O(m+n) 时间，结点存储 O(m+n)，合并辅助空间 O(1)。

## 边界与易错点

空表、两表空、相同值均需考虑；-1 不是数据。Merge 复用原结点，合并后只将 C 当作结果表使用。

按考试数据处理：输入符合题面，长度和位序用 int，规模在可表示、可分配范围内。只用 stdio.h、stdlib.h，分配时仅做一次简短的 NULL 检查。剩余链表结点随进程结束回收，局部头结点不能 free。
