# 线性表：链式结构

## 题目与约定

来源：[CG 第二章题面](https://cg.sau.edu.cn/assignment/problemContent.jsp?problemID=bgGy7iWz3yM)，作业 12208。
代码：[01_线性表_链式结构.c](01_线性表_链式结构.c)，独立编译提交。

读 n、n 个元素、插入位序和插入值，最后读待删除的值。带头结点，插入位序 1..n+1；越界跳过插入并继续删除。删除第一个匹配值。

样例输入：

```text
5
1 2 3 4 5
3 6
4
```

样例输出：

```text
1 2 6 3 5
```

## 思路与函数

ReadList 尾插建表 → Insert 按位插入 → DeleteValue 按值删除 → PrintList 输出。Locate 单独提供按值查找，返回首个匹配位序，未找到返回 0；题目没有查询输入，main 不额外输出。

## 关键代码

```c
s->next = p->next;
p->next = s;
```

## 样例推演

插入位置 3 的前驱是 2，把 6 接在 2 与 3 之间；删除 4 时，让前驱 3 指向 5，再释放 4。

## 复杂度

O(n) 时间，链表存储 O(n)，操作辅助空间 O(1)。

## 边界与易错点

空表、表头/表尾插入、位置 0 或 n+2、删除不存在值、重复值都要考虑。头结点不是第一个数据结点。

按考试数据处理：输入符合题面，长度和位序用 int，规模在可表示、可分配范围内。只用 stdio.h、stdlib.h，分配时仅做一次简短的 NULL 检查。剩余链表结点随进程结束回收，局部头结点不能 free。
