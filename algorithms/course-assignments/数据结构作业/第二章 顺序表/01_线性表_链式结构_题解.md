# 线性表 链式结构：输入、插入、查找、删除、输出

对应代码：[01_线性表_链式结构.c](01_线性表_链式结构.c)

来源：2026-2027 (1) 第2章 线性表-作业（非计分）。

## 1. 题目与约定

【问题描述】创建链式线性表，实现输入、插入、查找、删除与输出功能。

【输入形式】元素个数 n；n 个数据；插入位置与插入元素；要删除的元素。

【输出形式】输出处理后的线性表。

样例输入（`//` 是说明，不实际输入）：

~~~text
5               // 元素个数
1 2 3 4 5       // 输入数据
3 6             // 插入位置与插入元素，位置越界则不插入、继续运行
4               // 要删除的元素
~~~

样例输出：

~~~text
1 2 6 3 5
~~~

本题约定：

- 带头结点的单链表，头结点放在 `main` 的栈上（`Node head = {0, NULL}`），数据结点用 `malloc` 申请。
- 位序从 1 开始：插入位置 `pos` 表示插在第 `pos` 个结点之前。
- 插入合法范围 `1 ~ n+1`，`n+1` 表示插到表尾；越界时跳过插入，继续执行删除。
- 删除参数是**元素值**，不是位置；重复值只删第一个匹配结点，值不存在时链表不变。
- 题面要求“查找”，代码保留 `Locate` 返回位序；判题输入没有查询项，`main` 不调用它，所以不会多输出。

## 2. 思路

~~~text
尾插建表 → 找插入位置的前驱 → 插结点 → 找待删值的前驱 → 删结点 → 输出
~~~

1. **建表**：`tail` 始终指向表尾，每读一个元素接到 `tail` 后面，整体 O(n)。
2. **插入**：从 `head` 出发，`pos` 每走一步减 1，走完 `pos-1` 步后 `p` 就是第 `pos` 个位置的前驱，再执行 `s->next = p->next; p->next = s;`。
3. **删除**：`p` 从头结点出发，检查 `p->next->data`。命中后 `q = p->next; p->next = q->next; free(q);`。
4. **输出**：从 `head.next` 开始，元素之间一个空格，最后换行。

为什么循环盯住 `p->next` 而不是 `p`？单链表只能向后走，插入和删除都要改**前驱结点**的 `next`。拿到前驱，位置 1 和位置 n 的代码就完全一样，不用特判。

## 3. 关键代码

### 插入：数着步数找前驱

```c
void Insert(Node* head, int pos, int value)
{
    Node* p = head;
    Node* s = NULL;
    if (pos < 1)
    {
        return;
    }
    while (pos > 1 && p->next != NULL)
    {
        p = p->next;
        --pos;
    }
    if (pos > 1)
    {
        return;
    }
    s = (Node*)malloc(sizeof(Node));
    s->data = value;
    s->next = p->next;
    p->next = s;
}
```

- `pos = 1`：循环不进，插在头结点后面，即新的第一个结点。
- `pos = n+1`：循环停在表尾结点（`p->next == NULL` 时退出，此时 `pos == 1`），正常尾插。
- `pos > n+1`：表先走完，退出时 `pos > 1`，直接返回，链表不变。

### 删除：按值找前驱

```c
Node* p = head;
while (p->next != NULL)
{
    if (p->next->data == value)
    {
        Node* q = p->next;
        p->next = q->next;   /* 先接后继 */
        free(q);             /* 再释放 */
        return;
    }
    p = p->next;
}
```

- 删除第 1 个结点时，`p` 还是头结点，所以不会丢失表头。
- 删除表尾结点时，`q->next == NULL`，接上后表尾仍然是 `NULL`。
- 要删除**全部**同值结点，把 `return` 改成计数并让循环继续；删除后 `p` 不能前移。

### 查找

```c
int Locate(Node* head, int value)
{
    Node* p = head->next;
    int i = 1;
    while (p != NULL)
    {
        if (p->data == value)
        {
            return i;
        }
        p = p->next;
        ++i;
    }
    return 0;
}
```

## 4. 样例推演

建表后：

~~~text
head → [1] → [2] → [3] → [4] → [5] → NULL
~~~

`Insert(&head, 3, 6)`：`pos` 从 3 减到 1，`p` 依次经过 `head`、结点 1，停在结点 2：

~~~text
head → [1] → [2] → [6] → [3] → [4] → [5] → NULL
                ↑ p     ↑ s
~~~

`DeleteValue(&head, 4)`：`p` 依次经过 `head`、1、2、6、3，发现 `p->next` 的值等于 4：

~~~text
head → [1] → [2] → [6] → [3] → [5] → NULL
~~~

输出 `1 2 6 3 5`，与样例一致。

## 5. 复杂度

| 操作 | 时间复杂度 | 辅助空间 |
| --- | --- | --- |
| 尾插建表 | O(n) | O(1)（`tail` 指针） |
| 查找 `Locate` | O(n) | O(1) |
| 按位置插入 | O(n)，找前驱 | O(1) |
| 按值删除 | O(n)，找前驱 | O(1) |
| 输出 | O(n) | O(1) |
| 整体 | O(n) | 链表本身占 O(n) |

## 6. 边界情况与易错点

| 情况 | 正确行为 |
| --- | --- |
| 空表 `n = 0` | 插入位置 1 合法，可插入成单结点表 |
| 插入位置 0 或负数 | `pos < 1`，直接返回，不插入 |
| 插入位置 n+1 | 合法，接在表尾 |
| 插入位置 > n+1 | 表走完时 `pos > 1`，返回，不插入，程序继续 |
| 删除第 1 个结点 | 前驱是头结点，正常删除，不丢表头 |
| 删除表尾结点 | 接上 `NULL`，表尾判定正确 |
| 删除不存在的值 | 链表不变，不能报错退出 |
| 重复值 | 只删第一个匹配结点 |
| 删除后变空表 | 只剩头结点，输出空行，不能崩溃 |
| 输出格式 | 元素间一个空格，末尾无多余空格，最后换行 |

常见错误：

1. 用 `while (p != NULL && p->data != value)` 找待删结点，找到后删不掉——拿到的是结点本身，不是前驱。
2. `free(q)` 之后再读 `q->next`，访问已释放内存。
3. 插入时先 `p->next = s` 再 `s->next = p->next`，顺序反了会丢掉整条后继链。
4. 插入越界时直接 `return` 退出整个程序，导致后面的删除和输出没执行（本题要求继续运行）。
5. 输出每个元素后都加空格，末尾多一个空格，部分判题平台判错。
6. 头结点是栈变量，不能 `free(&head)`；只释放 `malloc` 出来的数据结点。
