# 数据结构作业（考试模拟练习）

本目录下的所有代码都用于**考试模拟和在线判题练习**，按“算法题标准”写，不按工程标准写。

## 代码标准

- 每题一个单文件 `.c`，自带 `main`，直接读标准输入、写标准输出，可整份提交。
- 只写解题必需的结构和函数：建表、插入、删除、查找、输出；不拆 `.h`、不建工程、不写构建脚本。
- 用 `scanf` / `printf`，不打印提示语和菜单，输出格式与样例严格一致（空格、换行都不能多）。
- 不做工程级防御：不层层返回错误码，不模拟分配失败（判题环境假设内存充足）；但指针操作仍要保证不越界、不重复释放、`free` 后不再访问。
- 注释只标接口用途、复杂度和关键约定；作业要求“关键语句加注释”时，在插入、删除、边界判断等关键行补注释，但不逐行翻译代码。
- 排版遵守根目录 [目录.md](../目录.md)：Allman 花括号、4 空格缩进、指针星号贴类型（`Node* p`）。
- 删除的结点立即 `free`；整张表在 `main` 返回后由进程回收，不额外写 `DestroyList`。
- 第 3 章起作业要求**不使用数组**（除非题面明确要求），栈和队列用动态结点/链表实现。

## 各章作业要求

| 章节 | 题量 | 关键要求 |
| --- | --- | --- |
| 第 2 章 线性表（非计分） | 21 题 | 掌握线性表的逻辑结构与顺序/链式两种存储结构 |
| 第 3 章 栈和队列 | 28 题 | 编程题必做；不能使用数组（题面强制要求除外）；熟练掌握顺序表和链表两种写法；查重率 ≤ 30%；关键语句加注释 |

“查重率 ≤ 30%”意味着代码要有自己的组织方式，不照搬网络模板；本项目统一用 `Node* p` 风格的链表写法，正好也能避免和别人完全雷同。

## 交付物

每题只交两个文件：

1. `xxx.c`：完整、可编译、可直接提交的题解；
2. `xxx_题解.md`：题目约定、思路、关键代码、复杂度、边界与易错点。

不放 `build.bat`、`.exe`、`.obj`、截图等多余文件。

## 题解格式

1. 题目与约定（含样例输入输出）
2. 思路（算法步骤）
3. 关键代码（只摘核心片段）
4. 样例推演（指针怎么走）
5. 复杂度
6. 边界情况与易错点
