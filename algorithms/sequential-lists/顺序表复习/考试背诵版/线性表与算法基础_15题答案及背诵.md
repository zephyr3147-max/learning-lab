## 二、逐题解析

### 第 1 题：顺序存储线性表的插入、删除复杂度

题目：对于顺序存储的线性表，增加、删除结点的时间复杂度为（）。

选项：A. O(n)、O(n)；B. O(n)、O(1)；C. O(1)、O(n)；D. O(1)、O(1)。

答案：**A**。

原因：顺序表用连续存储，一般插入需要把后续元素右移，删除需要左移，最坏都要移动与表长同数量级的元素。

注意：这里按一般位置操作的最坏复杂度作答。固定容量且空间足够时，尾插和尾删可为 O(1)，不能把特殊位置当成全部情况。

### 第 2 题：线性链表不具有的特点

选项：A. 所需空间与线性表长度成正比；B. 随机访问；C. 插入与删除时不必移动元素；D. 不必事先估计所需存储空间大小。

答案：**B，随机访问**。

链表不能像数组一样直接通过下标定位第 i 个元素，通常要沿 next 指针逐个寻找。所谓“不必移动元素”是指不用搬动一整段元素，只改变链接；寻找插删位置仍可能花 O(n)。

### 第 3 题：哪一种是线性数据结构

选项：A. 树；B. 图；C. 广义表；D. 链表。

答案：**D，链表**。

链表用于实现线性表，元素之间是线性的先后关系。树、图是非线性结构；广义表允许嵌套子表，按本题常见分类不归入普通线性结构。

### 第 4 题：算法时间复杂度取决于什么

选项：A. 问题的规模；B. 待处理数据的初态；C. A 和 B；D. 输出的数据。

答案：**C，A 和 B**。

对给定算法，执行次数通常与输入规模及输入情况有关。例如插入排序处理已有序与逆序的数据，移动次数不同。

严谨区别：指定“最坏时间复杂度”后，是把同规模输入中的最坏情况归纳为 n 的函数；并非所有算法的复杂度都随初态改变。本题按常见课程措辞选 C。

### 第 5 题：一个算法应该是什么

选项：A. 程序；B. 问题求解步骤的描述；C. 满足封闭性；D. A 和 C。

答案：**B，问题求解步骤的描述**。

算法描述怎样解决问题，程序则是算法的一种具体实现。算法不一定用程序语言表达，也可以用文字、流程图、伪代码表达。

常背的五个特性：有穷性、确定性、可行性、输入、输出；不是“封闭性”。

### 第 6 题：与数据存储结构无关的术语

选项：A. 循环队列；B. 链表；C. 哈希表；D. 栈。

答案：**D，栈**。

“栈”描述后进先出的访问规则，不规定采用数组还是链表。数组实现的是顺序栈，链表实现的是链栈。

本题中的“循环队列”按常见教材中的数组循环队列理解；“链表”“哈希表”也包含具体存储组织含义。

### 第 7 题：带头结点单链表的空表条件

选项：A. head == NULL；B. head->next == NULL；C. head->next == head；D. head != NULL。

答案：**B，head->next == NULL**。

题目默认是带头结点的非循环单链表。空表仍有头结点，但头结点后面没有数据结点：

```text
head → 头结点 → NULL
```

对比记忆：

| 结构 | 常见空表条件 |
|---|---|
| 不带头结点的非循环单链表 | head == NULL |
| 带头结点的非循环单链表 | head->next == NULL |
| 带头结点的循环链表 | head->next == head |

头指针是一个指针变量，头结点是一个真实存在的结点，两者不是同一个概念。

### 第 8 题：在 p 结点之后插入 s 结点

选项：

- A. p->next = s; s->next = p->next;
- B. s->next = p->next; p->next = s;
- C. p->next = s; p->next = s->next;
- D. p->next = s->next; p->next = s;

答案：**B**。

先让新结点 s 指向 p 原来的后继，再让 p 指向 s：

```c
s->next = p->next;
p->next = s;
```

```text
插入前：p → q
插入后：p → s → q
```

如果先写 p->next = s，再写 s->next = p->next，第二句就变成 s 指向自己，还丢失了原来的后继入口。

前提：p 有效，s 是已创建、可插入的新结点。这里展示的是链接步骤，不包括申请内存。

### 第 9 题：顺序表在第 i 个位置插入的复杂度

选项：A. O(0)；B. O(1)；C. O(n)；D. O(n²)。

答案：**C，O(n)**。

按从 1 开始的位置规则，要把原第 i 到第 n 个元素右移，移动数量为 n-i+1，加上写值、更新长度等常数操作，一般最坏是 O(n)。

题目未限定 i 为表尾，不能按尾插的特殊情况选 B。

### 第 10 题：链表不具有的特点

选项：A. 插入、删除不需要移动元素；B. 可随机访问任一元素；C. 不必事先估计存储空间；D. 所需空间与线性表长度成正比。

答案：**B，可随机访问任一元素**。

与第 2 题考点相同：顺序表支持按下标随机访问，普通链表需要顺序访问。不要把“能找到一个元素”误认为“支持 O(1) 随机访问”。

### 第 11 题：静态链表中的指针表示什么

选项：A. 内存地址；B. 数组下标；C. 下一元素地址；D. 左、右孩子地址。

答案：**B，数组下标**。

静态链表把结点放在数组里，用整数下标表示链接关系，这个整数常叫“游标”。例如 next = 5 表示后继结点位于结点数组的第 5 号下标。

区别：普通指针链表保存结点地址；静态链表的游标保存数组下标。静态链表虽然用数组保存结点，逻辑顺序仍由游标决定，不必等于数组下标顺序。

### 第 12 题：经常尾插、头删，选哪种链表

选项：A. 单链表；B. 仅有头指针的单循环链表；C. 双链表；D. 仅有尾指针的单循环链表。

答案：**D，仅有尾指针的单循环链表**。

尾指针 rear 可直接定位尾结点，而循环链接又让尾部能够直接找到头部，因此尾插与头删都可 O(1)。这正对应队列的“尾部入队、头部出队”。

不带头结点时，非空表的首结点是 rear->next；若带头结点，rear->next 指向头结点，再由头结点找到第一个数据结点。

普通仅有头指针的单链表，要尾插就得先寻找尾结点，通常 O(n)。双链表若另外维护尾指针也能实现 O(1) 尾插，但选项 C 未明确此配置；本题常见指定答案是 D。

### 第 13 题：线性表的定义

题目：线性表是具有 n 个（）的有限序列，n >= 0。

选项：A. 表元素；B. 字符；C. 数据元素；D. 数据项。

常见标准答案：**C，数据元素**。

标准表述：线性表是 n 个数据元素组成的有限序列，n = 0 时为空表。通常还要求元素具有相同的数据类型或共同的数据特征。

“数据元素”与“数据项”的区别：例如一条学生记录是一个数据元素，其中的学号、姓名、成绩是多个数据项。

措辞提醒：A 的“表元素”可作为“线性表中的数据元素”的近义说法。按标准定义题一般选 C，但截图未给官方判题依据；如果平台真正按多选计分，不能仅凭截图确认 A 是否也接受，须核对课程讲义或官方答案。这里不把这种措辞歧义冒充成已确认的系统答案。

### 第 14 题：连续存储时地址的关系

选项：A. 一定连续；B. 一定不连续；C. 不一定连续；D. 部分连续，部分不连续。

答案：**A，一定连续**。

连续存储就是使用连续的存储单元。对等大小元素，第 i 个元素的首地址相对前一个增加一个元素的大小，不是说两个 int 的首地址数值只相差 1。

顺序表强调物理存储连续；链表只要求逻辑上能通过链接找到后继，不要求各结点地址连续。

### 第 15 题：哪一种是非线性数据结构

选项：A. 树；B. 字符串；C. 队；D. 栈。

答案：**A，树**。

树中一个结点可以有多个孩子，形成分支关系。字符串、队列、栈属于线性结构，其中栈和队列是操作受限的线性表。

## 三、考前最小背诵清单

1. 线性表：n 个数据元素的有限序列，n >= 0；数据元素不等于数据项。
2. 线性结构：顺序表、链表、栈、队列、字符串；非线性结构：树、图。
3. 顺序表：地址连续、按位访问 O(1)、一般插删最坏 O(n)。
4. 链表：普通按位访问 O(n)，不搬动整段元素，但寻找位置可能 O(n)。
5. 带头非循环单链表判空：head->next == NULL。
6. 带头循环链表判空：head->next == head。
7. p 后插 s：先 s->next = p->next，再 p->next = s。
8. 静态链表：游标是数组下标，不是结点地址。
9. 尾插、头删：仅有尾指针的单循环链表，两种操作可 O(1)。
10. 算法是步骤描述；程序是具体实现。五个特性：有穷、确定、可行、输入、输出。

## 四、复杂度与易混点

| 操作 | 顺序表 | 普通单链表 |
|---|---|---|
| 取第 i 个元素 | O(1) | 最坏 O(n) |
| 按值查找 | 最坏 O(n) | 最坏 O(n) |
| 一般位置插入、删除（包括定位） | 最坏 O(n) | 最坏 O(n) |
| 已知前驱结点，插入或删除其后结点 | 仍可能移动 O(n) 个元素 | 链接调整 O(1) |
| 尾插 | 固定容量且未满时 O(1)；倍增动态数组均摊 O(1) | 仅有头指针时通常 O(n) |

只背“链表插删 O(1)”是不完整的，必须说明已经取得所需结点或前驱。只有目标单链表结点而没有前驱，也不能把一般删除一概写成 O(1)。

“不必预估存储空间”通常针对动态结点链表。静态链表仍需要数组容量，不能把动态链表特点套到所有数组实现上。

## 五、C 与 C++ 对比（本节只记原理）

| 考点 | C 中的表示 | C++ 后续可对应的工具 |
|---|---|---|
| 动态顺序表 | 动态数组、长度、容量 | vector |
| 指针链表 | struct、next、malloc/free | 自定义类或 list |
| 栈、队列规则 | 数组或链表接口 | stack、queue |

换语言不改变结构的基本复杂度；例如 vector 中间插入仍要移动元素。

## 六、自测练习与易错点记录

### 3 道基础题

1. 为什么带头结点的非循环单链表不能用 head == NULL 判断空表？提示：空表的头结点还在。
2. 静态链表的 next = 8 表示什么？提示：想数组下标，不是整数地址。
3. 顺序表尾删是否也要移动全部元素？提示：区分特殊位置与一般位置。

### 2 道提高题

1. 仅有头指针和仅有尾指针的单循环链表，尾插复杂度各是多少？提示：比较能否直接取得尾结点。
2. 已知单链表结点 p，删除其后继，与从头寻找并删除第 i 个元素的总复杂度有何不同？提示：是否包含定位。

### 1 道综合编程题

用 C 的带头结点单链表实现队列：维护头、尾指针，实现初始化、尾插入队、头删出队、判空、销毁。提示：重点检查首次入队、删掉最后一个元素、分配失败和释放后的指针状态；不要把头结点作为数据元素输出。
