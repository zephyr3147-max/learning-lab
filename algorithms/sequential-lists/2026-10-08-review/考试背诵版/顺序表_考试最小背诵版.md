# 顺序表：C 语言考试最小背诵版

## 1. 先明确本版本的用途

这份代码采用**固定容量数组**，用于复习顺序表最核心的取值、查找、插入、删除算法。所有代码放在一个 `.c` 文件中，不拆分头文件，不需要 `#pragma once`，也不需要 C++ 语法。

它不是所有考试的唯一标准：题目若规定结构体、函数名、下标规则或返回值，应按题目调整。题目要求动态扩容时，不能直接交这个固定容量版本。

同目录的 `顺序表_考试最小背诵版.c` 就是下面的完整代码，可单独编译。它与上级目录的动态扩容版是两个独立程序，**不要一起编译**，否则会有两个 `main`。

建议背诵顺序：结构体 → 初始化 → 按位取值 → 按值查找 → 插入 → 删除。遍历和 `main` 用来理解调用，不必机械背诵。

## 2. 基本原理：数组 + 有效长度

顺序表把逻辑上相邻的元素放在连续的存储单元中。这里用数组实现：

```text
数组下标：     0    1    2    3   ...   99
有效元素：    10   20   30   未使用区域
接口位置：     1    2    3
length = 3，MAXSIZE = 100
```

- `data` 保存元素，`length` 记录当前有多少个有效元素。
- 有效区域是 `data[0]` 到 `data[length-1]`；空表时没有有效元素。
- “顺序”指存储位置连续，不代表数值已经排序。`30、10、20` 也能组成顺序表。
- 数组下标从 0 开始，本版本的接口位置从 1 开始：第 `i` 个元素在 `data[i-1]`。
- 不必把整个数组清零。初始化只需设置 `length = 0`，之后先插入，再读取。

数组可直接通过下标定位，因此按位取值快；但中间插入或删除会影响后续元素的位置，因此需要移动元素。

## 3. 完整单文件代码

约定：表指针 `L` 必须有效，先初始化，保持 `0 <= length <= MAXSIZE`。输出参数指向表外的有效整数变量。Get/Insert/Delete 返回 `1` 表示成功、`0` 表示失败；Locate 返回第一个匹配位置，找不到返回 `0`。Delete 的输出参数可为 `NULL`，表示不用接收被删值。

```c
#include <stdio.h>

#define MAXSIZE 100
typedef int ElemType;

typedef struct
{
    ElemType data[MAXSIZE];
    int length;
} SqList;

/* 初始化：把顺序表设为空表，只将 length 置为 0，不清零数组。
 * 参数 L：待初始化的表地址；无返回值。O(1)。
 */
void InitList(SqList *L)
{
    L->length = 0;
}

/* 按位取值：读取第 i 个元素，不改变原表。
 * 参数 L：表地址；i：位置（1..length）；e：接收结果的变量地址。
 * 返回 1 表示成功，0 表示失败；失败不修改 *e。O(1)。
 */
int GetElem(const SqList *L, int i, ElemType *e)
{
    if (i < 1 || i > L->length || e == NULL)
        return 0;
    *e = L->data[i - 1];
    return 1;
}

/* 按值查找：从头查找第一个值等于 e 的元素，不改变原表。
 * 参数 L：表地址；e：要查找的值。
 * 返回从 1 开始的位置，找不到返回 0。最坏 O(n)。
 */
int LocateElem(const SqList *L, ElemType e)
{
    for (int j = 0; j < L->length; ++j)
        if (L->data[j] == e)
            return j + 1;
    return 0;
}

/* 插入：将 e 插到第 i 个位置，后续元素右移，表长加 1。
 * 参数 L：表地址；i：位置（1..length+1）；e：要插入的值。
 * 返回 1 表示成功；位置非法或表满返回 0，原表不变。最坏 O(n)。
 */
int ListInsert(SqList *L, int i, ElemType e)
{
    if (i < 1 || i > L->length + 1 || L->length == MAXSIZE)
        return 0;
    for (int j = L->length; j >= i; --j)
        L->data[j] = L->data[j - 1];
    L->data[i - 1] = e;
    ++L->length;
    return 1;
}

/* 删除：删除第 i 个元素，后续元素左移，表长减 1。
 * 参数 L：表地址；i：位置（1..length）；e：接收被删值的变量地址，
 * 可传 NULL 表示不接收。返回 1 表示成功；位置非法返回 0，
 * 原表和输出值不变。最坏 O(n)。
 */
int ListDelete(SqList *L, int i, ElemType *e)
{
    if (i < 1 || i > L->length)
        return 0;
    if (e != NULL)
        *e = L->data[i - 1];
    for (int j = i; j < L->length; ++j)
        L->data[j - 1] = L->data[j];
    --L->length;
    return 1;
}

/* 遍历输出：依次打印有效元素，以空格分隔，最后换行；空表只换行。
 * 参数 L：表地址；不改变原表，无返回值。O(n)。
 */
void PrintList(const SqList *L)
{
    for (int j = 0; j < L->length; ++j)
        printf("%d ", L->data[j]);
    printf("\n");
}

/* main 是调用示例；考试只写题目要求的部分。 */
int main(void)
{
    SqList L;
    ElemType e;
    InitList(&L);
    if (!ListInsert(&L, 1, 10) || !ListInsert(&L, 2, 30)
        || !ListInsert(&L, 2, 20))
        return 1;
    PrintList(&L);
    if (!ListDelete(&L, 2, &e))
        return 1;
    printf("deleted: %d\n", e);
    PrintList(&L);
    if (!GetElem(&L, 2, &e))
        return 1;
    printf("second: %d\n", e);
    printf("position of 30: %d\n", LocateElem(&L, 30));
    return 0;
}
```

预期输出（遍历每行末尾有一个空格）：

```text
10 20 30
deleted: 20
10 30
second: 30
position of 30: 2
```

在配置好 C 编译器的 VS Code 中，只编译运行这个 `.c` 文件即可；它不依赖上级目录的 `SqList.h` 或 `SqList.c`。

## 4. 核心算法怎么记

### 4.1 初始化、取值和查找

初始化：`L->length = 0`。`L` 是结构体指针；`L->length` 等价于 `(*L).length`。调用 `InitList(&L)` 才能修改原表。

取值：先检查 `1 <= i <= length`，再用 `*e = data[i-1]` 把结果传回调用者。传 `&e` 是为了让函数能修改外部变量。`const SqList *L` 表示这个接口只读表，不修改表。

查找：从下标 `0` 扫到 `length-1`；找到就返回 `j+1`。这里返回的是位置，不是元素值，也不是数组下标。

### 4.2 插入：后向前，右移，写值，长度加一

把 `20` 插到 `10、30、40` 的第 2 个位置：

```text
原表：          10 30 40
data[3]=data[2] 10 30 40 40
data[2]=data[1] 10 30 30 40
data[1]=20      10 20 30 40
最后 length 从 3 变为 4
```

必须从后往前移动，否则会先覆盖尚未搬走的元素。循环记成：

```c
for (int j = L->length; j >= i; --j)
    L->data[j] = L->data[j - 1];
```

插入位置允许 `1..length+1`，尾插时循环不执行。插入之前还必须检查表满，否则写 `data[MAXSIZE]` 会越界。

### 4.3 删除：保存值，前向后，左移，长度减一

删除 `10、20、30、40` 的第 2 个元素：先保存 `20`，再让 `30`、`40` 依次向左补位，最后 `length` 从 4 变为 3。

```c
for (int j = i; j < L->length; ++j)
    L->data[j - 1] = L->data[j];
```

删除位置只允许 `1..length`。尾删无需移动元素；旧末尾值可以留在数组中，只是已经不属于有效区。

**背诵口诀：插入后往前，删除前往后；插入可到长加一，取删只能到表长。**

## 5. 不必另背的基础操作

以下片段假设已有初始化后的 `SqList L`，需要输出结果时已声明 `ElemType e`。Get/Insert/Delete 的返回状态仍要检查。

| 操作 | 复用已有代码 |
|---|---|
| 判空 | `L.length == 0` |
| 求长 | `L.length` |
| 判满 | `L.length == MAXSIZE` |
| 清空 | `L.length = 0;` |
| 头插 x | `ListInsert(&L, 1, x)` |
| 尾插 x | `ListInsert(&L, L.length + 1, x)` |
| 头删 | `ListDelete(&L, 1, &e)` |
| 尾删 | `ListDelete(&L, L.length, &e)` |
| 修改第 i 个值 | 先确认 `1 <= i <= L.length`，再写 `L.data[i-1] = x;` |

本版本的数组就在结构体里面，没有 `malloc`，所以不用 `free(L.data)`。函数结束时，局部变量 `L` 的存储随它的生命周期结束；不要把静态容量版本和动态数组版本的销毁方法混用。

## 6. 时间复杂度和适用场景

令 `n = length`，`i` 为合法接口位置：

| 操作 | 时间复杂度 | 原因 |
|---|---|---|
| 初始化、判空、求长、清空 | O(1) | 只访问或修改 length |
| 按位取值、按位修改 | O(1) | 直接用下标定位 |
| 按值查找 | 最坏 O(n) | 可能扫描全部元素 |
| 插入 | O(n-i+2)，最坏 O(n) | 移动 n-i+1 个元素，再写新值 |
| 删除 | O(n-i+1)，最坏 O(n) | 移动 n-i 个元素，再更新长度 |
| 尾插、尾删 | O(1) | 此固定容量版本无需移动，满表则插入失败 |
| 遍历 | O(n) | 访问所有有效元素 |

以上算法的辅助空间均为 O(1)。表自身预留 `MAXSIZE` 个元素的存储，按容量参数分析为 O(MAXSIZE)，不能把“已预留容量”误写成“只占 length 个格子”。

典型应用：

1. **按编号读取数据**：例如学生成绩表，需要频繁访问第 k 条记录，按位访问方便。
2. **遍历、排序和统计**：例如求最大值、平均值，对连续数组扫描即可。
3. **有序表查找**：元素已按同一比较规则排好序时，可以使用二分查找；本代码的 LocateElem 是顺序查找，不要求有序。
4. **尾部增删较多、数据规模有上限**：例如暂存一批整数。本版本超过 100 个时会失败，需要增大容量或改成动态版。

不擅长的场景：频繁在头部、中间插入或删除，因为需要移动很多元素。链表可以避免整段移动，但按位置找到结点通常仍需要遍历，不能简单说链表任何插删都是 O(1)。

## 7. 动态扩容题：在此基础上改哪里

如果题目要求空间不足时扩容，就把固定数组换成 `ElemType *data`，再增加 `capacity`；初始化申请内存，插入前检查容量，用临时指针接收 `realloc`，结束时 `free(data)`。

```c
/* 仅展示关键步骤，不是可直接替换整份程序的完整动态版本。
 * newCapacity 须已计算好，并已检查翻倍和字节数溢出。
 */
ElemType *temp = realloc(L->data,
    (size_t)newCapacity * sizeof(*temp));
if (temp == NULL)
    return 0;
L->data = temp;
L->capacity = newCapacity;
```

动态版需要包含 `<stdlib.h>`。不要直接写 `L->data = realloc(...)`，否则失败返回 NULL 时会丢失原地址。成功后数组地址可能改变，旧元素指针不能继续使用。

前面已经完成的动态模块化版本保存在上级目录的 `SqList.h`、`SqList.c`、`test.c`；详细扩容讲解见上级目录 `复习指南.md` 第 4.1 节。这次不修改那些文件。

固定容量尾插 O(1)；倍增动态容量的连续尾插均摊 O(1)，触发扩容的单次尾插最坏 O(n)。

## 8. 考前检查与练习

### 一页总结

只抓住四件事：结构体保存数组与长度；位置转下标减一；插入向右移动且从后往前；删除向左移动且从前往后。

### C 与 C++ 的对应关系（先了解，不要求现在背）

| 当前 C 写法 | 后续 C++ 写法 | 本次重点 |
|---|---|---|
| struct + 普通函数 | 可用 class 封装数据和接口 | 先掌握指针传参 |
| 固定容量数组 | 可用标准库 vector 管理动态数组 | 理解容量与有效长度不同 |
| 手动移动元素 | vector 的插删接口帮你移动 | 中间插删仍可能 O(n) |

### 3 道基础题

1. 表长为 3 时，哪些位置允许插入？哪些位置允许删除？提示：插入多一个末尾位置。
2. `LocateElem` 在数组下标 2 找到目标时返回什么？提示：接口位置从 1 开始。
3. 在 `10、20、30` 的第 2 个位置插入 99，数组发生哪些赋值？提示：从最后一个有效元素开始搬。

### 2 道提高题

1. 编写函数删除表中所有值等于 x 的元素，保持其余元素相对顺序。提示：一个下标读，一个下标写，避免每次删除都移动后缀。
2. 给非递减有序表添加有序插入接口。提示：先考虑满表，再从尾部向前寻找插入位置。

### 1 道综合编程题

输入 n 个整数（`0 <= n <= MAXSIZE`），建立顺序表；插入一个指定位置的整数；删除一个指定位置的元素并输出被删值；查找目标值的位置；最后输出表。提示：输入时控制元素数量，每次插删检查返回值，不要读取失败调用留下的输出参数。

### 易错点自查（尚未代表你实际犯过）

- [ ] 接口位置 i 对应 `data[i-1]`，查找成功返回 `j+1`。
- [ ] 插入合法范围是 `1..length+1`；取值、删除是 `1..length`。
- [ ] 插入先判满，并从后往前搬；删除从前往后搬。
- [ ] 插入后 `++length`，删除后 `--length`，查找不改变长度。
- [ ] `length == 0` 不能取第一个元素；遍历不能写 `j <= length`。
- [ ] 用 `&L` 传入原表地址，用 `&e` 接收结果。
- [ ] 固定数组不调用 free；动态数组必须正确释放。
- [ ] 遵守题目给定的类型、下标和返回值约定。
