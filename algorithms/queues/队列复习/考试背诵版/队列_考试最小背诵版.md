# 队列：考试最小背诵版（C，单文件）

## 1. 原理：先进先出 FIFO

队列是一种限制两端操作的线性表：队尾入队，队头出队。
10、20、30 依次入队，出队顺序为 10、20、30，像排队先到先走。

本版使用固定数组循环队列，不在每次出队后整体移动元素。
front 指向队头元素；rear 指向下一次入队的空位置，不是当前尾元素。
数组末尾之后用 % MAXSIZE 回到 0，循环使用已经出队留下的空间。

| 约定 | 公式 |
| --- | --- |
| 空队列 | front == rear |
| 满队列 | (rear + 1) % MAXSIZE == front |
| 长度 | (rear - front + MAXSIZE) % MAXSIZE |
| 入队后 rear | (rear + 1) % MAXSIZE |
| 出队后 front | (front + 1) % MAXSIZE |

为区分满与空，牺牲一个单元，MAXSIZE=100 时最多保存 99 个元素，MAXSIZE 必须至少为 2。
所有 Q 参数必须指向已初始化的有效对象，输出参数指向队列外有效变量。
DeQueue 允许 NULL 输出参数；GetHead 不允许 NULL。

## 2. 完整单文件代码

main 是自动演示，不用输入。考试按具体题目改 main，接口不必重写。

```c
#include <stdio.h>
#define MAXSIZE 100
typedef int ElemType;

typedef struct
{
    ElemType data[MAXSIZE];
    int front;
    int rear;
} SqQueue;

/* 初始化：front 指向队头，rear 指向下一次入队位置。O(1)。 */
void InitQueue(SqQueue *Q)
{
    Q->front = 0;
    Q->rear = 0;
}

/* 判空：队头与下一次入队位置重合。O(1)。 */
int QueueEmpty(const SqQueue *Q)
{
    return Q->front == Q->rear;
}

/* 判满：牺牲一个单元，避免与判空条件冲突。O(1)。 */
int QueueFull(const SqQueue *Q)
{
    return (Q->rear + 1) % MAXSIZE == Q->front;
}

/* 求长：循环距离；最多保存 MAXSIZE-1 个元素。O(1)。 */
int QueueLength(const SqQueue *Q)
{
    return (Q->rear - Q->front + MAXSIZE) % MAXSIZE;
}

/* 入队：在 rear 处写入，再让 rear 循环后移。O(1)。 */
int EnQueue(SqQueue *Q, ElemType e)
{
    if (QueueFull(Q))
    {
        return 0;
    }
    Q->data[Q->rear] = e;
    Q->rear = (Q->rear + 1) % MAXSIZE;
    return 1;
}

/* 出队：读取 front 处数据，再让 front 循环后移。O(1)。 */
int DeQueue(SqQueue *Q, ElemType *e)
{
    if (QueueEmpty(Q))
    {
        return 0;
    }
    if (e != NULL)
    {
        *e = Q->data[Q->front];
    }
    Q->front = (Q->front + 1) % MAXSIZE;
    return 1;
}

/* 取队头：只读，不删除；失败不改输出。O(1)。 */
int GetHead(const SqQueue *Q, ElemType *e)
{
    if (QueueEmpty(Q) || e == NULL)
    {
        return 0;
    }
    *e = Q->data[Q->front];
    return 1;
}

/* 清空：固定数组不用 free，恢复初始下标。O(1)。 */
void ClearQueue(SqQueue *Q)
{
    Q->front = 0;
    Q->rear = 0;
}

/* 自动演示：顺序入队 10、20、30，按 10、20、30 出队。 */
int main(void)
{
    SqQueue Q;
    InitQueue(&Q);
    if (!EnQueue(&Q, 10) || !EnQueue(&Q, 20) || !EnQueue(&Q, 30))
    {
        return 1;
    }
    ElemType e;
    if (GetHead(&Q, &e))
    {
        printf("head: %d\n", e);
    }
    while (DeQueue(&Q, &e))
    {
        printf("%d", e);
        if (!QueueEmpty(&Q))
        {
            printf(" ");
        }
    }
    printf("\n");
    ClearQueue(&Q);
    return 0;
}
```

输出：

```text
head: 10
10 20 30
```

## 3. 逐步执行和记忆

初始 front=rear=0。
入 10：data[0]=10，rear=1。
入 20：data[1]=20，rear=2。
出 10：读 data[0]，front=1，数组不整体移动。

假设数组容量是 5，front=3、rear=1：有效元素按下标 3、4、0 排列，长度为 (1-3+5)%5=3。
逻辑顺序不能简单用 for(i=front;i<rear;i++) 遍历，因为 rear 可能小于 front。
最后一个元素出队后 front==rear，未必都是 0，这仍是空队列。
Clear 才主动把两个下标重置为 0。

进阶版增加 size 计数，因此可以利用全部容量，判空/满改为 size==0、size==capacity；不要混用两套判定公式。

## 4. 复杂度与应用

初始化、判空/满、求长、入队、出队、取队头、清空都是 O(1)。
固定容量存储为 MAXSIZE 个元素，不使用动态内存，不需要 free。
适用：广度优先搜索、树的层序遍历、任务缓冲、消息排队、生产者消费者的基础模型。
本章接口不是线程安全队列；多线程应用还需要同步机制。

## 5. 与 C++ 的联系

| C | 后续 C++ |
| --- | --- |
| struct + 函数 | class 封装 |
| 循环数组手工维护下标 | 可自定义容器或使用标准容器 |
| EnQueue / DeQueue / GetHead | std::queue 的 push / pop / front |

std::queue 的 pop 不返回元素；通常先 front，再 pop。现在不必学习模板才能理解队列。

## 6. 练习与易错点

3 道基础题：

1. MAXSIZE=6 的本版最多存几个元素？
2. front=4、rear=2、MAXSIZE=6，长度是多少？
3. 为什么 rear 指向下一次入队位置，而不是已有尾元素？

2 道提高题：

1. 把牺牲单元版改成保存 size 的版本，推导满/空条件。
2. 循环队列绕回数组开头后，如果扩容，如何保持逻辑顺序？

综合题：读入 n 个整数入队，出队 k 个，再入队 m 个；按出队顺序输出剩余值。
先用一个小容量手工画 front/rear 的变化，再写代码。

易错点记录：

- [ ] 满与空都写成 front==rear。
- [ ] 忘记 % MAXSIZE 导致数组越界。
- [ ] 以为有效元素一定在一段连续下标中。
- [ ] 误以为最后一次出队后 front、rear 必须都为 0。
- [ ] 混用“留空一格”和“size 计数”公式。
- [ ] 每次出队移动所有元素，导致 O(n)。
